# Workshop Tools 回归清单

## 1. 小精灵转交

- [ ] 普通成品从小精灵转给场上英雄，原 item handle 出现在英雄物品栏。
- [ ] 转给等待区英雄成功。
- [ ] 英雄 0~8 槽已满时拒绝，装备仍在小精灵。
- [ ] 可叠加物品转交后数量正确。
- [ ] 合成组件转交触发合成时，不重复、不消失。
- [ ] 战斗阶段点击转交被服务端拒绝。

## 2. 技能升级

- [ ] 场上英雄准备阶段可点击原版 `+` 升级技能。
- [ ] 等待区英雄准备阶段可点击原版 `+` 升级技能。
- [ ] 升级后技能点正确减少，重铸/换阵容后不恢复。
- [ ] 战斗阶段仍不能让玩家手动干预或升级。

## 3. 默认行动规则

- [ ] 新英雄第一次打开面板只有 1 条默认普攻规则。
- [ ] 不按主动技能数/装备数自动补满。
- [ ] 玩家新增、删除、排序的规则不被 normalize 删除。
- [ ] 删除最后一条后恢复 1 条默认兜底。

## 4/6. 敌人行动与当前关绑定

- [ ] 第 1 关所有实际生成敌人主动攻击。
- [ ] 第 2 关所有实际生成敌人主动攻击。
- [ ] 英雄关 3、4、5、6、7 个敌人分别全部注册，不固定为 3。
- [ ] 每个敌人使用当前 `entry.ai_profile`，日志不出现演示三英雄名字。
- [ ] 敌人引导施法时 fallback 不重复下攻击命令。

## 5. 关卡差异

- [ ] 第 1 关和第 2 关单位模型/单位名不同。
- [ ] 运行时日志无 stage 1/2 duplicate。
- [ ] 全 30 关唯一性校验只报告真实重复组合。

## 7/8. UI

- [ ] 展开按钮显示 `<`，收起按钮显示 `>`。
- [ ] 收起后按钮为完整 44×44，不是一条竖线。
- [ ] 1920×1080、2560×1440 和常见 UI 缩放下不溢出。
- [ ] 英雄商店根背景透明，后方英雄可见。
- [ ] 单个报价卡、文字和购买按钮仍清楚可读。

## 9. 矩形战场

- [ ] 两个 1200×900 准备区（总 2400×900）的尺寸和外墙正确。
- [ ] 准备阶段中线阻挡有效。
- [ ] 开战中线门消失，寻路立即连通。
- [ ] 单位不能走出外圈；位移出界后能回正。
- [ ] 下一关中线门恢复。

## 10. 原版商店

- [ ] 场上英雄在准备阶段可从原版商店购买。
- [ ] 等待区英雄在准备阶段可购买。
- [ ] 购买物品进入当前目标英雄，而不是丢失或错误进入其他英雄。
- [ ] 原版合成与背包移动可用。
- [ ] FIGHT 阶段购买订单被阻止。
- [ ] 本地 Tools 和上传后的专用服务器各测试一次。
