# Hammer：两个紧凑准备区组成的矩形战场

Lua 不能替代 `.vmap` 的外墙和导航阻挡。本页是第 9 项必须完成的地图修改。

## 尺寸

默认尺寸为两个相邻的 1200×900 准备区。每个区略大于原 1040×760 待命区：

```text
总战场：2400 × 900
左侧我方区：x -1200 ~ 0，y -450 ~ 450
右侧敌方区：x 0 ~ 1200，y -450 ~ 450
```

可以整体平移或旋转，但当前 Lua 默认按 X 轴左右划分；需要旋转时同步改 `ArenaController:BoundsForUnit()`。

## 必需实体

### 边界标记

放置三个 `info_target`：

| targetname | 位置示例 | 用途 |
| --- | --- | --- |
| `rpg_arena_min` | `(-1200, -450, 地面Z)` | 整体左下角 |
| `rpg_arena_max` | `(1200, 450, 地面Z)` | 整体右上角 |
| `rpg_arena_center` | `(0, 0, 地面Z)` | 中线与攻击移动目标 |

### 中线视觉门

把中线树墙/能量墙/模型组成一个或多个可 Enable/Disable 的实体，统一 targetname：

```text
rpg_mid_gate_visual
```

如果使用真实树木，它们只作为视觉效果。Lua 会在开战时清除中心 220 半径树木，但下一关重新关闭中线必须依赖可恢复的 visual/nav gate，不能依赖已被摧毁的树。

### 中线导航阻挡

使用适合当前 Dota 2 Hammer 版本的导航阻挡实体覆盖中线，targetname：

```text
rpg_mid_gate_nav
```

它必须响应：

```text
Enable
Disable
```

准备阶段 Enabled；开始战斗 Disabled；结算后重新 Enabled。

## 外圈

在 2400×900 外圈建立永久不可穿越边界：

- 地图几何墙或悬崖；
- 对地面单位有效的 nav blocker；
- 视觉边界与实际阻挡位置一致；
- 不要只用树木，因为伐树、位移或路径更新可能造成缺口。

Lua 每 0.2 秒把越界战斗单位拉回边界内 64 单位，但这只是异常兜底，不能承担正常寻路碰撞。

## 出生和站位

- 我方站位点全部位于左侧准备区，建议 x `-1000 ~ -250`、y `-350 ~ 350`。
- 敌方站位点全部位于右侧准备区，建议 x `250 ~ 1000`、y `-350 ~ 350`。
- 双方最近站位离中线至少 150，避免门关闭时模型重叠。
- 仓库小精灵不要放在可战斗单位扫描范围的敌方一侧；建议放在左下角独立平台或明确标记为 Courier。

## 验证

1. 准备阶段双方不能跨中线。
2. 点击开始后 visual 与 nav gate 同一帧关闭/失效。
3. 双方能通过中线接敌，不会绕远路。
4. 右键矩形外位置会被钳制到边界内。
5. 闪烁、推拉、传送类效果把单位送出后，0.2 秒内被纠正回来。
6. 下一关准备阶段中线门重新出现并阻挡。
