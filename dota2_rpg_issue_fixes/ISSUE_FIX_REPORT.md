## 关键设计决定

### 装备转交

旧错误路径通常是“读取名称 → 删除源物品 → 新建目标物品”。只要创建或 `AddItem` 失败，装备就永久消失。新路径是：

```text
验证来源和目标
→ 从小精灵 RemoveItem（不销毁）
→ 把同一 handle AddItem 给英雄
→ 验证目标库存发生变化
→ 失败则把同一 handle 放回小精灵
```

### 敌人行动

敌方单位来源只有当前关的 `spawned_enemy_units`。配置与单位按顺序绑定：

```text
expand(level.enemies by count)
→ expandedEntries[i] 对应 spawnedEnemyUnits[i]
→ 绑定该 entry.ai_profile
→ FIGHT 时对所有实际单位启用行动
```

### 战场

Lua 只能控制逻辑和实体开关，不能可靠替代 Hammer 的地图边界。外圈必须使用可阻挡寻路的地图几何/导航实体；Lua 的 0.2 秒越界纠正只是防止位移技能或异常指令逃出战场的第二层保护。
