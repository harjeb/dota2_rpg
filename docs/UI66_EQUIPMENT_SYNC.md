# UI66：装备同步补强

关联 `dota2_rpg-or41`。用户反馈购买装备后装备页偶尔不更新。

## 修改

- 准备阶段原有持续库存签名检查保留；签名新增同一物品实体的当前充能，修复同槽、同名、同实体但数量/充能变化未触发装备刷新这一漏项。
- 原生购买事件不再无条件强推全部英雄/商店状态；由实际库存变化或钱包变化触发，避免提前到达/重复的购买通知制造重复广播。
- 库存同步已广播商店时，当前更新不再因技能变化重复广播一次。
- 新测试同时保护原有延迟入包、后续合成、同名实体替换处理，验证事件标记消耗后仍能发现实际库存变化，稳定库存连续40轮无额外广播。

这不是重写购买流程；也未证明修复了用户所遇到的所有偶发刷新场景。若新局仍复现，需要记录所买装备、所选英雄以及金币是否扣除，以区分原生购买落点、库存同步与界面渲染。

## POINT技能选取位置参照

在该技能规则的「条件设置」顶部，「目标阵营：自己 / 友方 / 敌方」下方的选项中切换。下方「目标筛选」「目标优先级」决定具体参照单位。POINT技能朝该单位当前位置施法，不改变技能原生受影响阵营。
