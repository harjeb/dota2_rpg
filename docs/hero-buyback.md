# 英雄买活行动（UI81）

在战役英雄的行动列表里手动添加「买活」，保持开启后，英雄阵亡且公共金币足够时自动扣款复活。默认行动不包含买活；关闭该行即可停止自动买活。买活独立于存活英雄的施法/攻击评估，不受行动行顺序、目标筛选或附加条件影响。

## 费用

以英雄当前等级 L 计费，等级范围 1–30。基础费用为 `base = 100 + 50L + 5L²`，简单难度倍率为 `0.75`，默认难度为 `1`，困难难度为 `1.25`。最终费用为 `floor(base × multiplier / 5 + 0.5) × 5`，即四舍五入到最接近的 5 金币。

费用由服务端权威计算和扣款。编辑器使用商店状态 `rpg_shop_state` 发布的 `campaign_difficulty` 显示当前价格；未收到难度或难度无效时使用默认倍率。打开行动或重新打开设置时使用最新已收到的难度和英雄等级。

每名英雄每场战斗仅可成功买活一次，买活后再次阵亡不能在同一场战斗再次买活。下一场战斗开始时重置次数；同一关卡失败后的重试也属于新的战斗尝试。只有成功买活才消耗本场次数，金币不足不会消耗次数。

## 复活和结算

- 只适用于战役当前上阵的己方真实英雄，不适用于敌人、召唤物、待命英雄和竞技场。
- 保留同一个英雄实体、等级、装备和成长；在本轮开战位置复活，恢复满血满蓝，保留当前技能和物品冷却。
- 清除旧的追击、等待、持续移动和施法状态观察，重新接入行动引擎。移除原生复活产生的泉水无敌，恢复自动索敌。
- 不朽盾、冥魂大帝以及尸王的原生重生先执行，不为正在重生的英雄扣买活费。
- 每次战斗结束检查先执行买活，再判断双方是否全灭。因此全员阵亡但仍有英雄能成功买活时，战斗继续。
- 多人同时阵亡按阵容顺序依次检查和扣款，金币不足者跳过；不会为同一名英雄的重复买活规则重复扣款。
- 战斗超时优先结算，不会在超时后扣费续战。战斗结束或准备阶段不执行买活。
- 原生复活调用失败且英雄仍死亡时退还本次费用，并停止对该次失败死亡重试，避免重复扣费或无限延长战斗。

## 验证范围

自动化检查覆盖规则保存/恢复、界面动作选择、全部 30 级 × 3 难度共 90 个价格、编辑器两个入口的权威难度接线、公共钱包、原生重生互斥、团灭判定和复活后的战术状态重置。Lua 使用原生 API 替身，不能替代 Dota 实机验证；仍需在游戏中检查实际复活位置、原生技能状态和复活后的攻击/施法。
