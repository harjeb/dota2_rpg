条件设置：每个控件做什么

逐项记录当前窗口中的按钮、输入框、菜单和状态反馈。每项说明用途、选项与默认值、显示条件、操作结果，并提供可展开的字段对照。

没有匹配项。试试更短的关键词，或清除搜索。

01 · 范围与当前结构

以当前 UI52 的实际条件编辑器为准。用途是重设计 UI 时核对功能、参数和交互；范围仅为“条件设置”弹窗。本文中的搜索、目录和打印按钮属于文档阅读工具。

4 + 4 + 2条件 / 筛选 / 排序槽
36 / 35 / 14有名称选项数（各另有“不限制”）
按动作切换持续移动 / 普通站位

规则的判断顺序

使用条件全部满足→筛选合格目标→按第 1、2 项排序→检查原生可用性并执行

同一条规则中的条件是“并且”；表达“或者”通常需要两条规则。空槽表示不增加限制。无目标技能仍可通过筛选检查是否存在合格的观察目标，不会因此变成指向技能。

动作名称在弹窗外的规则行选择。选择技能时自动将第一条推荐方案套用到草稿，之后可以修改并应用；重新打开已有规则不会再次覆盖已编辑条件。弹窗内“选择技能 / 装备”用于引用条件观察对象；“启动技能”用于识别持续移动的触发事件。两者都不替换本条动作。

弹窗从上到下的实际顺序

标题栏（右上角红色重置）→ 目标阵营 → 使用条件 4 行 → 目标筛选 4 行 → 优先级 2 行 → 动作选项（持续移动或站位）→ 射程外行为 → 特定技能目的地 → 开关技能（支持时）→ 错误提示 → 取消 / 应用。

下拉选择器实际由按钮和自定义选项面板构成，不是原生 HTML 下拉框。每次只展开一个菜单；再次点击同一按钮收起，选中后收起。禁用选项可通过悬停说明原因。

02 · 弹窗按钮、草稿与反馈

此处覆盖窗口内所有独立操作按钮；条件行和动作选项中的菜单按钮在后续分组列出。

重置

红色按钮 · 标题栏右上角
用途
清空条件并恢复开关设置。
选项 / 默认
清空 4 使用条件、4 筛选、2 排序；支持的技能开关默认开启。
何时出现
允许编辑时。
修改 / 点击行为
恢复默认目的地，清除移动 / 站位设置并按默认值重建；移动重新选敌与循环恢复开启。保留动作、目标阵营与射程外行为。只改草稿，应用后提交。

重置不会再次套用技能推荐条件；取消可放弃本次修改。

重设计对照：字段 / 控件 IDV2ClearConditions

应用

按钮
用途
校验并提交本条规则的草稿。
选项 / 默认
无输入。
何时出现
一直显示；只读或严格模式下能力数据缺失时禁用。
修改 / 点击行为
读取所有参数、规范化数值，检查必填名称和技能兼容性；出错留在窗口显示原因；通过本地检查后提交并关闭。

服务端还会独立校验。窗口关闭不表示服务端一定接受；异步拒绝会在规则同步提示中显示。

重设计对照：字段 / 控件 IDRuleSettingsApply / RuleSettingsError

直接关闭，不调用应用，不提交草稿。重新打开从规则当前数据开始。

04 · 条件行内的每一种参数框

这些控件由所选条件动态出现。同一个“数值”标签可能表示人数、层数、生命值或距离，重设计时应保留其语义差异。

百分比 %

数字文本框
用途
用于自身、目标或小小抓取单位的生命 / 魔法比例。
选项 / 默认
默认 50；范围 0–100。
何时出现
条件标识含 _pct_ 时。
修改 / 点击行为
填写 40 表示 40%；保存时转换成后台比例值。

不是 0.4。≥ / ≤ 包含边界。

重设计对照：字段 / 控件 IDvalue / V2_{use|target}{index}_value

数值

数字文本框
用途
按条件表示人数、动作次数、技能充能、状态层数、绝对生命值、已损失生命值或目标距离。
选项 / 默认
一般默认 1；详细上限随条件变化，见每个条件卡片。人数、次数、层数建议填整数。
何时出现
选择带 value 字段且不是百分比的条件时。
修改 / 点击行为
当前文本框接受数值文本，小数不会自动变成整数；空白或非数值回退默认，越界值会被界面夹到允许范围。

“本场次数 < 1”允许首次下令；“< 0”永远不通过。距离不是像素。

重设计对照：字段 / 控件 IDvalue / V2_{use|target}{index}_value

半径

数字文本框
用途
规定“附近人数 / 没有敌人”的观察范围。
选项 / 默认
默认 600；范围 0–3000，单位为 Dota 世界距离。
何时出现
使用 U10/U11/U12 或筛选 F11/F12。
修改 / 点击行为
使用条件以自己为圆心；目标筛选以候选目标为圆心，并按该目标阵营判断敌我。

不计圆心本人。对敌人使用 F11“附近友军”，数到的通常是其他敌人。半径不会修改技能伤害范围。

重设计对照：字段 / 控件 IDradius / V2_{use|target}{index}_radius

秒

数字文本框
用途
按条件表示战斗时间门槛、近期受伤窗口、距动作下令时间、连招窗口、持续施法时长或状态剩余时间。
选项 / 默认
默认 2；一般 0–86400；战斗时间 U13/U14 为 0–120。
何时出现
选择带 seconds 的条件时。
修改 / 点击行为
时间允许小数。例如“最近受伤 2 秒”观察过去两秒，“持续施法 ≥ 2 秒”观察当前这次持续施法。

不是设置技能冷却或持续时间。“距动作下令至少”在本场从未下令时不成立，首次延迟应考虑战斗时间。

重设计对照：字段 / 控件 IDseconds / V2_{use|target}{index}_seconds

选择技能 / 装备

分英雄菜单按钮
用途
指定本条件观察哪个英雄的哪项动作。
选项 / 默认
默认“当前英雄的本条动作”；菜单按英雄分组，展示技能 / 物品图标和名称。
何时出现
U21/U22/U23/U24/U39/U40/U41/U42。
修改 / 点击行为
选择后记录动作和可选英雄引用；点“当前英雄的本条动作”清除引用。引用英雄离场或已无该动作时不能按其他人替代。

没有独立的“英雄文字输入框”，英雄身份来自菜单分组。下令记录不代表命中；U39 的成功链与 U42 的原生阶段口径不同，见对应条目。

重设计对照：字段 / 控件 IDaction_id + action_actor / V2_use{index}_action_id

选择状态

状态菜单按钮
用途
从已观察 / 已声明状态中选择条件观察对象。
选项 / 默认
初始为空；以状态名称和可用技能图标识别，悬停可查看内部名称。
何时出现
具有 / 没有状态、状态层数或剩余时间条件。
修改 / 点击行为

没有状态不按 0 层 / 0 秒处理；同名多实例取可读最大值，永久状态视为无限时间。

重设计对照：字段 / 控件 IDmodifier / V2_{use|target}{index}Modifier

选择施法阶段

菜单按钮
用途
根据观察到的技能生命周期状态触发动作。
选项 / 默认
默认“持续施法中”；共 9 个阶段，详见下方阶段表。
何时出现
仅 U42。
修改 / 点击行为
选择阶段并配合技能 / 装备引用；切换菜单项显示对应阶段名和悬停解释。
重设计对照：字段 / 控件 IDvalue / V2_use{index}Phase

敌方目标

头像菜单按钮
用途
锁定当前关卡的一个具体敌人。
选项 / 默认

何时出现
仅目标筛选 F39；要求目标阵营为敌方。

05 · 通用动作选项与特殊目的地

目标在射程外时

菜单按钮
用途
决定是否主动靠近当前目标以满足原生距离。
选项 / 默认
等待进入射程、自动接近目标；新规则通常等待，已有追击设置会保留。
何时出现
常驻。
修改 / 点击行为
“自动接近目标”保存 forced=true；仍遵守控制、持续施法保护和原生可用性。

与“站位方式”不同：这里解决够不够得着，站位选项规定站到什么位置。

重设计对照：字段 / 控件 IDforced / V2ApproachSelect

目的地

菜单按钮
用途
为特定灵体 / 残焰动作选择位置来源。
选项 / 默认
按目标筛选与优先级选择位置（默认）、自身位置；激活残焰额外有离自身最近 / 最远的残焰、最靠近敌人的残焰、距最近敌人最远的残焰。
何时出现
仅灰烬之灵放置残焰 / 激活残焰、上古巨神先祖之魂 / 移动灵体。
修改 / 点击行为
切换保存目的地策略；由专用执行逻辑解析合法原生位置。

“安全残焰”只比较与敌人的距离，不能理解为保证安全；其他技能没有此控件。

重设计对照：字段 / 控件 IDdestination / V2DestinationSelect

开关技能

菜单按钮
用途
设置技能期望的开启或关闭状态。
选项 / 默认
开启（On，默认）、关闭（Off）。
何时出现
仅原生支持 Toggle 或自动施法的技能。
修改 / 点击行为
自动识别原生机制：Toggle 保存 desired_toggle_state，自动施法保存 desired_autocast_state；两者均支持时优先 Toggle。明确关闭会保存并在重开时保留；重置恢复开启。

控制期望状态；自动施法的后续施放由原生机制决定。

重设计对照：字段 / 控件 IDV2ToggleRow / V2ToggleSelect

06 · 持续移动专用控件

只有本条动作为“持续移动”（sustained_move）时显示。单独选择“践踏”或“地雷滚滚”技能本身不会显示这些控件。

缩地：循环穿越 / 践踏：绕行 / 地雷滚滚：绕行

3 个预设按钮
用途
填写对应技能的移动配置。
选项 / 默认
缩地=循环穿越；践踏=绕行；地雷滚滚=绕行。均距离 150、重新选敌开、循环开、允许中断关、方向自动；前两者 15 秒，地雷滚滚 20 秒。
何时出现
仅持续移动。
修改 / 点击行为
只覆盖 movement_* 字段，保留目标、条件和排序，并填写原生 Buff 与触发技能。需应用才提交。

最长时间是保险上限，原生 Buff 先结束就先停。预设不负责释放技能。

重设计对照：字段 / 控件 IDV2MovementPreset_shukuchi / _trample / _gyroshell

移动方式

菜单按钮
用途
决定增益期间沿什么路径移动。
选项 / 默认
跟随（新草稿默认）、穿过、绕行、循环穿越。
何时出现
仅持续移动。
修改 / 点击行为
跟随：靠近到指定距离；穿过：越过目标到其另一侧；绕行：围绕目标生成路径点；循环穿越：按筛选和排序依次穿过不同目标。

原生寻路与碰撞决定实际路线；循环穿越的换下一目标不同于“目标失效后重新选敌”。

重设计对照：字段 / 控件 IDmovement_mode / V2_movement_mode

绕行方向

菜单按钮
用途
规定绕行路径点的转向。
选项 / 默认
自动（默认）、顺时针、逆时针。
何时出现
持续移动时一直显示；主要影响绕行模式。
修改 / 点击行为

重设计对照：字段 / 控件 IDmovement_direction / V2_movement_direction

关联原生增益 / 选择状态

自定义菜单 + 状态菜单
用途
选择自己身上必须存在的原生增益，作为移动激活条件。
选项 / 默认
关联增益菜单仅有“自定义”；状态菜单列出已观察 / 已声明状态，新草稿为空。
何时出现
仅持续移动。

11 · 重设计时需要保留的联动与边界

下面记录现有交互契约，不规定新界面必须采用什么视觉布局。

草稿状态与提交

打开：复制规则→修改草稿 / 切换重建→应用：本地校验→服务端接受 / 拒绝

改阵营会重建正文，已有输入须先读取。选择技能自动将第一条推荐方案应用到草稿；重新打开已有规则保留编辑结果，不重复套用推荐。移动预设仅覆盖移动参数。取消不提交。英雄、规则或关卡在编辑期间变化时，需要防止把旧草稿写入新对象。

显示 / 启用关系对照

依赖应呈现的结果
选择不同条件类型仅出现该类型需要的百分比、数值、半径、时间、状态、动作引用、阶段或敌方头像。
动作 = 持续移动出现 3 个移动预设、移动方式、方向、自定义增益 / 状态菜单、触发技能、时间、距离、3 个布尔选择。
动作 = 普攻 / 技能出现普通站位 3 控件；普攻没有“原生施法距离”选项。物品没有站位组。
动作属于灵体 / 残焰 4 个技能显示目的地；仅激活残焰额外显示 4 个残焰选项。
实时原生能力限制禁用不兼容的阵营与条件；按原生能力显示技能开关，错误由错误提示说明。
只读 / 非准备阶段 / 编辑对象变化不能保存失效草稿；正文只读或关闭窗口。取消仍可用。

值得在新 UI 中明确表达的现状

  • “移动距离”随模式变换含义；最好同时展示单位和具体用途。
  • “启动技能”只是事件来源，不会施放技能；状态菜单只选择 Buff，完整预设则填写整组移动参数。
  • 目标筛选的附近敌我关系相对于候选目标；U11 附近敌人数不等于预计技能命中人数。
  • 多数条件数字框会回退 / 夹取数值，而移动与站位还有后端范围校验；应向用户说明最终提交值。
  • 选择“不限制”清除单槽；F39 菜单的“清除指定目标”也移除整项筛选。窗口没有另设“添加第五项”或“删除槽位”按钮。
  • 没有独立的动作英雄文本框、AOE 命中人数框或向量第二点输入。旧字段 min_aoe_hits 已移除，保存会清理；不要仅根据旧本地化名称恢复它们。
  • 菜单有禁用项、失效引用和只读信息三类状态；不能都画成“无选项”。
  • 本条规则的动作选择、启停、增删、上下移动位于弹窗外，不计入本控件清单。

12 · 填写示例与功能核对

给血量最低的队友治疗

目标阵营=友方；目标筛选 F01 百分比=70，F13 排除自己；优先级 P03 生命百分比最低，再 P01 距离最近。选择原生允许治疗友军的技能。若希望无合格队友时自用，移除 F13 并把第一优先级改为 P14。

践踏期间围绕敌人移动

在弹窗外添加“持续移动”动作规则，进入条件设置，点“践踏：绕行”；目标阵营=敌方，排序=距离最近，距离=150；重新选敌与循环默认开启，需要只移动一次时可明确关闭。另设践踏技能规则负责施放，并通常把移动规则排在技能规则上方。Buff 结束就停止，不会走满 15 秒才停。

保存关闭状态

选择支持原生开关或自动施法的技能，将“开关技能”设为关闭并应用。重新打开仍显示关闭；点击右上角红色重置后恢复开启，同时清空条件，应用才提交。
