# 永久历史排行榜

游戏只保留历史总榜，不按赛季重置。积分榜包含红心耗尽的失败和全程通关；速通榜只包含从第 1 关连续推进到第 30 关的全通。每名玩家在每张榜上保留一个最佳成绩，同时保存每次终局记录和当时的玩家名称。

## 本地主机自动上传

当前游廊使用本地主机运行。玩家进入更新后的地图，正常游玩到全通或红心耗尽，终局会自动提交成绩、显示排名和破纪录祝贺。无需 Steam 网页授权、验证码、专服密钥或外部 cfg。

按产品要求暂不做身份认证和防作弊验证。游戏代码从引擎取得账号、名称并累计关卡结果，HTTP 接口公开接受成绩；后台只核对字段、范围、计分公式及通关条件，无法据此证明玩家身份和实际对局过程。新记录及 API 返回标记 `source: local_host_reported`，迁移前的旧记录标记 `legacy`。来源不改变永久榜排序。

插件仍将编辑器、作弊模式、技能调试和手选关卡识别为练习，不自动提交；这些本地判断不构成防作弊保护。SteamID64 从引擎的 32 位账号 ID 按十进制位计算，避免 Lua 浮点数精度丢失。

旧 Valve 专服配对流程已经停用，取钥脚本和验证码 UI 已移除，`/api/v1/server-pairing` 返回 404。已有 Worker Secret 和本机外部 cfg 不再参与上传。发布条目为 [团战模拟器EX（3799645167）](https://steamcommunity.com/sharedfiles/filedetails/?id=3799645167)；更新本机插件后，还须上传该条目并新建大厅，才能让工坊玩家使用新脚本。

## 计分 v1

设 `H` 为剩余红心（0–5），`S` 为通过关数（0–30），`R` 为各关胜利时剩余时间之和（毫秒）：

```text
基础乘区 = floor(100000 × (1 + 1.1 × H / 5) × (1 + S / 30))
时间加区 = floor(R / 1000) × 10
通关加区 = 全通时 1000000，否则 0
总分 = 基础乘区 + 时间加区 + 通关加区
```

红心归一化增幅为 110%，关卡为 100%，两者相乘。通关奖励保证当前 5 心、30 关、每关 120 秒的范围内，所有全通高于所有未全通。完美成绩为 1,456,000 分。计分版本为 `hearts-stages-v1`，后端根据提交的原始指标重新计算总分。

速通时间遵循本项目约定：**每关胜利时剩余时间之和，越小排名越高**。实际耗时另存。失败尝试的时间不计入这一指标，胜利恰好剩余 0 毫秒有效。全程耗时从首次开战到终局，包含重试和中间准备阶段，不参与速通排名。

## 结算与记录

终局弹窗显示分数拆分、红心、通过关数和两张榜的个人最佳成绩排名。排名与破纪录标志在后台接受提交的同一事务中捕获，显示的是提交时名次。全服纪录须严格优于原榜首，个人纪录须严格优于自己的原记录；首次上榜单独祝贺。相同成绩不覆盖先前记录，同值由较早达成者优先。

每次终局只生成一次提交 ID，网络重试复用同一请求；重开后旧回复不会弹回新局。终局面板不会自动消失，普通单关奖励仍保持原有自动关闭行为。同步失败时保留本地计分并说明状态，不显示虚构名次。当前重试最多 4 次，游戏进程退出后不会继续重试。

## 服务和验证

服务地址：`https://dota2-rpg-leaderboard-api.dota2-rpg-leaderboard-worker.workers.dev`

- `POST /api/v1/runs`：公开终局提交，JSON，最多 8192 字节，无需 Authorization。
- `GET /health`：健康检查。
- `GET /api/v1/leaderboards/score`：积分榜。
- `GET /api/v1/leaderboards/speedrun`：速通榜。
- `GET /api/v1/players/{steam_id}`：该玩家最佳成绩和历史。

查询支持 `limit`（1–100）和 `offset`（0–10000）。插件中的 `data/leaderboard_config.lua` 只保存公开地址、版本和 Workshop ID。Cloudflare 后台源码、迁移和运维文件位于本机 `backend/leaderboard-worker/`，按要求不提交 Git。

离线回归执行 Lua 计分/提交模块和真实 Panorama XML/JS 的面板替身；后台测试使用 SQLite 执行迁移及事务。远程 Worker + D1 验证免授权提交、重复请求、榜单及历史，只清理验证用的精确提交 ID。Dota 资源编译器检查 UI 资源。这些检查不代替用户实际运行工坊大厅的完整对局。
