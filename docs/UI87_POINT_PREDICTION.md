# UI87 固定距离预判位置

在条件设置的目标筛选、排序之后提供「预判位置」：关闭 / 前方 / 后方；开启时距离默认 200，可填 0～3000 游戏距离单位。仅普通点地技能和物品可用；单位目标、无目标、矢量、特殊目的地覆盖不适用。切换到不支持的动作会清除配置。

执行顺序：现有目标过滤（包含同时满足 / 按优先级）→现有目标排序→固定选中首位目标→前后偏移→原生落点与施法距离检查。偏移落点不能用时跳过本规则，不回退脚下或另一目标。允许追击时沿用现有追击流程，并在每次重新选点时更新偏移。

方向使用共享战斗观察中的实际水平位移；站定、首次观察、记录超过 0.5 秒或位置跳变时回退目标当前朝向。距离为 0 时使用当前位置。输出点使用地面高度。该功能没有技能延迟模型、命中率、命中人数门槛、自动躲避或释放后修改落点。

配置以 target.prediction_direction / prediction_distance 保存，平面消息与快照使用同名字段。已有规则默认关闭；开启缺省距离为 200；服务端拒绝非法方向、非有限数及越界距离。两种语言标记同步为 UI87。

验证：`LUA_BIN=luajit python scripts/test-all.py` 完整 134/134 组通过。新增测试覆盖实际移动与朝向差异、站定、前后与零距离、同帧记录、过期与闪烁轨迹、先排序再偏移、范围/追击、原生落点拒绝、CAST_POSITION 订单、保存/快照/旧规则转换及真实 HUD 面板替身中的配置恢复和动作切换。

验证边界：全部为离线 Lua 原生 API mock 和 Node Panorama panel double。运行 `scripts/install-addon.ps1 -Compile` 时默认 Dota 路径不存在，未安装、未执行 Workshop 编译或原生战斗验收。后续需在 Dota 环境验证 UI87 两份安装语言文件与源码一致，以及目标直线移动、站定、转向和追击过程中的实际点地落点。
