# 当前游戏条件完整中文清单（版本 9）

本清单逐项对应版本 9 的“条件设置”菜单：**25 个使用条件、34 个目标筛选、13 个目标排序，共 72 个选项**。中文名称按当前游戏文本原样列出；实际口径与文字有差异的地方单独注明。动作选项另列，不算入 72 项。

## 一、目前实现到哪一步

这些菜单项已有界面配置、序列化、服务端校验及战斗判断代码，不是待实现的设计列表。版本 9 已部署到本机 Dota 2 插件目录，完整自动回归和原生资源编译通过，73 个安装源文件与仓库一致。**尚未逐项进行游戏内实际验证**，因此“已实现并部署”不等于“每种英雄、状态和场景都已经实测成功”。实际验收跟踪：`dota2_rpg-jut`。

本版删除指定的 13 个选项。保留其他条目的原编号，编号空缺表示已删除，避免旧编号指向不同条件。

游戏入口：选择英雄 → 选择行动规则 → 条件设置。每条规则最多 **4 个使用条件 + 4 个目标筛选 + 2 个排序优先级**。同一组内全部满足才通过；排序先比较第 1 项，再比较第 2 项。留空表示不增加限制。修改后点击“应用”才提交，取消不应用草稿。每位英雄最多 32 条规则。

### 参数怎么填

- **P**：百分比，填 0～100，例如 40 表示 40%，不要填 0.4 表示 40%。
- **N**：数值门槛；人数、次数、层数使用整数，生命值等按对应数值填写。`≥`、`≤` 包含相等，`<` 不包含相等。
- **R / D**：Dota 世界中的距离单位；距离计算使用水平二维距离，不是屏幕像素。
- **T**：秒数。
- **动作名称**：通常填技能内部名称；留空使用本条动作。动作历史记录下令，不表示成功命中或施法完成。
- **状态名称**：填准确的原生 modifier 内部名称，不是中文技能名称；本版不提供英雄专属状态配方。

## 五、容易理解错的统计口径

### 人数与敌我关系

“存活友军数 / 敌人数”统计本场战斗观察列表，不限制距离。列表包含参战单位，以及通过原生搜索和归属关系识别到的其他存活单位；不能理解为整张地图的所有单位。存活友军总数包含施法者。

“附近人数”不计中心单位本人。使用条件的中心是施法者；目标筛选的中心是候选目标。**目标筛选中的敌我关系也相对于候选目标**：如果候选目标是敌人，“其附近友军”通常是其他敌方单位，“其附近敌人”通常是我方单位。

### 状态、伤害和动作记录

“任意友军最近受到伤害”排除施法者，但并不保证受伤的是最终选中目标。需要治疗受伤的那个人时，用目标筛选“目标最近受到伤害”，再结合目标生命门槛。

同名状态有多个实例时，层数或剩余时间当前取可读取实例中的最大值，不按施加者分别筛选。不存在的状态不会作为 0 层或 0 秒通过比较；永久状态按无限剩余时间处理。可驱散状态只读取原生 modifier 的增益/减益及可驱散标记，不判断本条技能能否实际移除它。

距上次动作下令的时间条件在没有历史记录时不成立。技能充能读取技能原生充能接口，不是任意英雄特殊资源，也不是普通物品堆叠数。

高级名称必须准确。例如错误的状态名称可能使“具有状态”永远不成立，使“没有状态”一直成立。部分原生观测不可用时，数值条件会拒绝通过，不能把没有观察数据视作正常的 0 值。

## 六、动作选项与基础施法支持

| 项目 | 当前行为 | 限制 |
|---|---|---|
| 目标模式 | 自动识别、对单位施法、对地点施法 | 必须是技能原生支持的模式，不能把纯单位技能改成任意地点技能。 |
| 圆形范围最少命中数 | 0 表示不检查；正数启用原生圆形半径的人数估计 | 是当前位置的估计，不是实测命中；不替代线形、锥形或矢量几何。 |
| 开关期望状态 | 默认行为、开启、关闭 | 开启和关闭建议分成两条规则并留出阈值间隔。 |
| 基础矢量施法 | 默认选原生射程内最近的合法目标，以目标为锚点，沿施法者到目标方向继续延长 150 单位定义第二点 | 第二点用于基本方向，不承诺实际长度、完美落点、弹射收益或第二次命中；无专用方向条件面板。 |
| 普通引导技能 | 按通用条件启动，引导期间保留施法保护 | 不添加特定英雄释放计时器、提前释放或专属后续动作。 |

条件全部通过后，仍要检查技能等级、可用状态、冷却、魔法、充能、控制状态、原生目标合法性等。“总是”不会跳过这些检查。无目标技能的目标筛选用于检查是否存在符合条件的单位，不会把原生无目标技能变成单位指向技能。

## 七、配置示例

| 目的 | 使用条件 | 目标筛选 | 目标排序 |
|---|---|---|---|
| 治疗低血量友军 | 总是，或自行增加魔法门槛 | 目标范围选友方；目标生命百分比 ≤ 70 | 生命百分比最低，然后距离最近 |
| 周围至少两个敌人时使用普通范围技能 | 附近敌人数 ≥ 2，填写合适半径 | 按技能原生目标类型设置 | 距离最近 |
| 尝试打断持续施法 | 总是 | 敌方；正在持续施法 | 距离最近；技能本身还必须能打断 |
| 对最近敌人进行基础矢量施法 | 总是 | 敌方；其余可留空 | 距离最近；使用技能原生矢量模式 |
| 仅在下令次数少于三次时考虑动作 | 本场动作使用次数 < 3，动作名称留空 | 按技能需要设置 | 按技能需要设置 |

这些是通用规则写法，不是逐英雄实战验收结果。“低血量或最近受伤”应写成两条规则；把两个条件写在同一条规则里表示二者必须同时满足。
