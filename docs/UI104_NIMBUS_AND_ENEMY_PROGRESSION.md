# UI104 — 雷云清理与敌方英雄成长

## 修正

- 原生宙斯雷云的单位名和类名均为 `npc_dota_zeus_cloud`，技能为 `zuus_cloud`。其原生属性为 `NO_ATTACK` / `MOVE_NONE`，普通可控召唤物路径不能可靠覆盖。现在单独跟踪双方上阵及替补英雄所属雷云，在非战斗阶段清除；全局类扫描补足遗漏生成事件和延迟归属。保留战斗阶段的原生落雷行为，不给雷云下攻击/移动指令，也不伪造死亡或奖励。
- 敌方自动加点原先明确跳过 `special_bonus`。现在按原生技能槽顺序识别四对天赋，排除属性加点；10/15/20/25 级各选第一侧，保留已经学习的另一侧，30 级补齐全部。使用 `UpgradeAbility` 注册原生天赋，拒绝升级时记录日志，不以 `SetLevel` 假装学习成功。玩家手动加点及天梯配置还原路径不变。
- 常规战役敌方英雄原先没有魔晶/神杖的额外成长配置。未显式指定 `quality_upgrades` 的英雄现在于15级获得魔晶永久效果、25级获得神杖永久效果，不占装备栏。已有物品配置保留；最终关显式配置（含空列表）优先，不套用默认曲线。野怪不继承英雄默认曲线。
