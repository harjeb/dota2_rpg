## 1. 全局规则

### 1.1 类型配比（沿用旧表结构）

每阵营 **20 张 = 增益 9 + 消耗 7 + 场地 4**，5 阵营共 100 张。

| 类型 | 行为 | 进化提升 |
| --- | --- | --- |
| **增益卡** | 被动能力持续本场；纯常驻卡开战即提供完整能力，联动卡按各自条件结算 | 数值 |
| **消耗卡** | **战前设定触发条件，战斗中自动触发**；本场用掉即失效，战后回到卡库 | 数值 + 本场可用次数 |
| **场地卡** | 开战生成**覆盖全战场**的场地效果（无范围、不锚定装备者、不跟随移动）；**开战生成后永不失效**（装备者阵亡 / 复活 / 换人都不影响） | 数值 |

### 1.1.1 本轮常驻设计标准

**纯常驻**指开战即拥有、整场有效，不要求低血、满蓝、计时解锁、印记、控制、施法次数或阵亡。常驻暴击、吸血、格挡、普攻附伤是持续拥有的战斗能力，正常攻击/承伤是结算事件，不是额外启动门槛；它们计入纯常驻。先等阵亡叠满后才常驻的卡不计入。

| 阵营 | 纯常驻增益 | 混合型 | 条件联动 | 纯常驻占比 |
| --- | ---: | ---: | ---: | ---: |
| 文明 | 7 | 0 | 2 | 7/9 |
| 神域 | 7 | 0 | 2 | 7/9 |
| 深渊 | 6 | 1（血渴） | 2 | 6/9 |
| 荒野 | 6 | 0 | 3 | 6/9 |
| **本轮合计** | **26** | **1** | **9** | **72.2%** |

「血渴」即使有常驻底值，也从严排除在纯常驻计数外。元素原稿保留，不纳入本轮验收。

### 1.2 等级分档（沿用 `CARD_SYNERGY_AXES_V1.md` §1.1）

所有效果写成 **Lv1 / Lv2 / Lv3** 三档，按**装载等级**结算。累计同名 1 / 2 / 3 份 → 拥有 Lv1 / Lv2 / Lv3；准备阶段可挑 `1 ≤ 装载等级 ≤ 拥有等级 ≤ 3`。

- **曲线 6 / 10 / 15**：表达 Lv1 较弱、Lv3 完整的递增方向，不强制所有卡逐项按此比例。本轮重设计的卡 **Lv1 也能独立起作用**，不把核心效果锁到高等级才提供。
- **COST 仍按装载等级**：普通 1/5/10、强力 1/6/15、顶级 1/8/20。
- 数值全部是占位，只表达 `Lv1 < Lv2 < Lv3`。

### 1.3 作用对象

本轮后四阵营若卡面明确指定敌人、攻击者自身、英雄本体或装备者，则按卡面对象结算；例如全队各自获得吸血，并不表示每人造成一次伤害就给全队各恢复一份。未指定例外的团队增益仍覆盖所有友方。常驻的生命/魔法上限在准备阶段结算、开战冻结；平值先加、百分比同组加算后乘上（例如厚皮与野性），不循环计算；幻象/重生形态继承与全队效果合并时同一卡只算一次。

**所有效果作用于所有友方**（`FACTION_CARD_MODE_DESIGN.md` §1.1），装备者只提供槽位。**场地卡覆盖全战场**（§1.6），没有范围概念。其余卡写明范围时，优先按卡面指定中心结算；本轮「撕咬鸡腿」以普攻主目标为中心。保留的元素范围卡沿用原稿，其具体周期/中心仍见 §9-9。**属性类效果**另有“**开战前生效**”时机（准备阶段结算、开战冻结，见 `FACTION_CARD_MODE_DESIGN.md` §5 与 `CARD_SYNERGY_AXES_CANDIDATES.md` §H），场地卡「共鸣领域」即此类（Lv1 / Lv2 **只给属性**，吃主属性合计的**增幅条款锁在 Lv3**）；本表里战斗内触发的加属性卡是否统一改用该时机，见 §9 待确认 12。

### 1.4 轴与图标（9 个图标封顶）

①生命 ②护盾 ③魔法 ④充能层数 ⑥控制 ⑦节奏 ⑧死亡印记 ⑨重生 ⑩施法。

- ⑤召唤物轴**并入重生**（召唤物的出口就是阵亡/献祭），共用 1 个图标。
- 每张卡在卡面**至多标 1 个**轴图标；**不带轴图标也完全正常**——不属于任何轴的卡（纯功能卡）就不带。
- **轴不是配比指标**：轴只是**可能的联动线索**（“这两张卡可能能凑一起玩”），不是必须满足的额度。**不设“每轴至少几张、至少几个阵营”这类硬门槛**，也不因为某轴只有 1 张而去凑卡。张数现状仅作参考，见 §2。
- 轴标签只是**卡面提示**，不代表一张卡“只能属于一个轴”；同一张卡可以同时沾几个轴的机制，只是卡面只标最想提示的那一个。

### 1.5 消耗卡：按"物品 / 神符"的思路设计

消耗卡不再是"受伤反弹"这类被动小效果，而是**一次性、限时、全队共享的强力 buff**，手感对标物品与神符：

| 设计要点 | 规则 |
| --- | --- |
| 触发 | **卡自带默认触发条件**（多数是"开战第 5 秒"），玩家可用 `FACTION_CARD_MODE_DESIGN.md` 的条件系统改成自己的条件；**不做战斗内手动点击** |
| 时效 | 多数是**限时 buff**："X 秒内全队……"，到期即结束 |
| 次数 | 本场可用次数 = 装载等级（**Lv1 / Lv2 / Lv3 → 1 / 2 / 3 次**） |
| 计数域 | 本文的消耗卡默认**全队共享次数**（因为是全队受益）；这是 §9 待确认项 |
| 强度 | 因为是限时 + 次数受限，允许出现"**X 秒内基础攻击力 +80%**"这种平时不会给的倍率 |

**后四阵营的消耗卡补充规则（本轮设计提案，不改元素原稿）**：

- 每卡每场仍是**全队共享 1 / 2 / 3 次**；一次触发只扣一次，不按受益人数扣次数。用完后本场不再触发。
- 时间型默认写成“第 t 秒起，每 k 秒”，例如第 5 秒起每 12 秒，即第 5 / 17 / 29 秒依次尝试，最多执行装载等级次。玩家改条件后也受同卡冷却约束。
- 事件型触发成功后，同卡进入 **12 秒内置冷却**。低血/低蓝属于状态条件：冷却结束时仍满足则可再用；施法、承伤、阵亡、印记击杀属于事件条件：冷却结束后等下一次新事件，不补发冷却期间的事件。多名单位同时满足只触发一次。
- 触发判定中的“任一友方英雄”只看存活上阵英雄本体；**受益仍按卡面全队**。比例以各单位自身上限计算，不用全队生命/魔法总和。卡片注明英雄限定的额外效果按卡面执行。
- 同卡同效果不叠层；再次触发刷新持续时间，护盾刷新到本次计算量、不累加。持续 buff 在消耗次数扣除后照常持续到到期。不同卡按对应叠加组结算；本轮减治疗与生命恢复合计最多 **−80%**，其他组上限仍由 §9 与实测校准。已保留的场地卡卡面不变，最终叠加限额属于本轮提案。
- 增益卡「共鸣增幅」与消耗卡「圣光圣油」增加的是接收方获得的护盾数值；同组加算。「恩泽」「圣光圣油」增加接收方治疗/恢复收益，每个来源每次只结算一遍，不同时在施放端和接收端重复放大。场地本身的来源/携卡英雄规则不变。
- 阵亡收益不计重生形态的死亡，不把召唤物自然到期/主动清理视为阵亡；重生形态不递归重生，同一张卡对同一单位只生效一份。
- 本轮直接伤害型消耗卡改为全场敌人；「撕咬鸡腿」的溅射以**被攻击目标**为中心。它们仍是一次性消耗效果或限时 buff，不是场地卡，也不参与场地计数与场地增幅。

本文用到的消耗卡范式（对照用户给的例子）：

| --- | --- | --- |

| 限时技能增强 | 10 秒内全队技能增强 **+20% / +30% / +45%** | 元素「奥术神符」 |

### 1.6 场地卡：覆盖全战场（已确认）

**场地卡覆盖整个战场，没有范围参数**：不锚定装备它的英雄、不跟随移动；战场内所有相关目标（按各卡效果，敌方或友方）无论距离多远都受影响。**装备者阵亡 / 复活 / 换人不影响已生成的场地**（见下条「永不失效」；旧稿「装备者阵亡则整场场地失效」作废）。场地卡占**通用槽**，不是召唤物，不占单位数、不被驱散。

- 强度旋钮只有 **Lv1 / Lv2 / Lv3 数值**，不再用「范围大小」区分强弱（旧稿「范围 500 更强」的说法作废）。
- **不同场地卡可以叠加**（已确认）：各自独立结算、同时作用于全场，所以"叠加"就是**场地数量本身**，跟站位无关。场地数量天然是一个可读的量，**场地流轴 + 场地卡「共鸣领域」**的思路草案见 `CARD_SYNERGY_AXES_CANDIDATES.md` §H。
- **永不失效**（已确认）：装备者阵亡、复活、换人都不影响已生成的场地，持续到本场战斗结束。因为不会被"击杀携带者"解除，场地层是最可靠的一层，强度刹车只剩 Lv 数值、通用槽机会成本与全局上限。
- **场地效果没有使用者**（已确认）：场地效果不归属装备它的英雄，**英雄自己的技能（含技能回血）不会被自己装备的场地卡放大**；"按**携卡英雄主属性合计**提高场地效果"（500 点 = +50% 封顶）是单向关系，只强化场地层。
- 多个不同场地卡可共存；唯一资产下同名场地卡不可能出现两张。
- **降属性 / 降生命上限可以致死**（已确认）：场地卡的「生命上限降低」（A-f3 血池）、「全属性降低」（W-f3 荆棘丛林）、「力量降低」（A-f2 恐惧领域）**允许把目标打到 0 生命并击杀**，不给 1 点生命保护。实现上不依赖原生生命上限钳制（原生钳制与力量下限不保证击杀），而是按**明确掉血**结算：上限/属性的降低量同步以 `DAMAGE_TYPE_PURE` + `DOTA_DAMAGE_FLAG_HPLOSS` 扣掉当前生命，来源标 `card_field`。**属性与上限数值本身仍要有下限**（力量/全属性不低于 0、生命上限不得降到 0 以下），该下限只约束数值、不阻止击杀。**（已确认）这三个效果逐次叠加累加、不设累加上限**：卡面数值是**每次结算的增量**（A-f2 每 5S −2/4/6 力量、A-f3 每 3S −20/30/40 生命上限、W-f3 每秒 −0.5/0.8/1 全属性）；战斗拖得越久压得越狠，累计扣空目标当前生命即击杀。实现上没必要为每次结算单独建 modifier，可用一个周期 modifier 自持累计量。

## 9. 待确认项

1. **消耗卡的次数计数域**：本文按**全队共享**（Lv1 / Lv2 / Lv3 → 1 / 2 / 3 次）。旧框架默认"各自计数"（`FACTION_CARD_MODE_DESIGN.md` §1.1），两者必须选一个并写进卡面。
2. **消耗卡的触发条件由谁定**：本文给了**内置默认触发条件**（多数"开战第 5 秒"），玩家可用条件系统覆盖。这与 §14-7 的"抽到就能用 vs 玩家配置"是同一个问题。
3. **⑥控制轴 10 张是否拆轴**（**可选，不做也行**）：若嫌 ⑥ 过大，把"减治疗"独立成候选池里的 D 伤口轴（顺带收容"伤口叠层"）；不拆就当前并入 ⑥。
4. **不带轴的 40 张卡是否要带轴**：这些卡（限时 buff、直接伤害、治疗、场地数值）不带轴，就是"不参与联动的工具卡"。**已定：不需要每张卡都带轴，不带就没问题**（轴只是可能的联动线索，不是指标）。
5. **场地卡的叠加上限**：治疗类场地（巫毒疗法 + 补给线）可以同队共存，合计每秒回血过高时必须设全局限额（`FACTION_CARD_MODE_DESIGN.md` §9 是旧 demo，需重定）。
6. **倍率类限时 buff 的上限**：「壮行烈酒」+80% 基础攻击力、「奥术神符」+45% 技能增强这类数字是**手感锚点**，不是平衡结论，需要在无尽模式实测波次里校。
7. **超上限加值的属性口径**（`FACTION_CARD_MODE_DESIGN.md` §6.2）：本表 100 张卡全部落地后，加值口径要重新选（不要百分比）。
8. **本轮 Lv1 的独立收益**：重设计卡的核心能力在 Lv1 即提供，等级提升数值/消耗次数；不再为追求高等级联动，让低等级只占槽不发挥作用。实测仍需验证 Lv1 的 COST 性价比。

9. **非场地范围口径**：本轮后四阵营的直接伤害型消耗卡已改全场；「撕咬鸡腿」是目标周围 350 范围溅射。保留的元素稿仍有「火盾」400 范围、「爆裂符文」500 范围，其具体结算中心/周期等歧义随元素后续校对处理；不在本轮改写已设计的卡。

10. **场地流的强度刹车**：场地卡已经全场、永久、可叠加，且不会因装备者阵亡而消失，所以没有"击杀携带者解除场地"的天然反制。刹车只剩四条：Lv 数值、通用槽机会成本（每张场地卡都要挤掉一张增益/消耗卡）、`FACTION_CARD_MODE_DESIGN.md` §9 全局叠加上限、以及该卡自身的"最多计 5 张"限额。**COST 档位由用户逐张分配**（不再统一提议顶级档）。**「共鸣领域」已定为：上限 5 张、属性开战前生效（Lv1 / Lv2 只给属性 +6n / +10n）、增幅条款锁 Lv3 且按携卡英雄主属性合计（500 点 = +50%，阈值保留、Σ 不含本卡 +20n、本卡 +20n 也不吃自己的增幅）。**
11. **「共鸣领域」的层级与归属——已定案**：**不设"核心卡 / 特殊卡"层级**，它就是一张**普通场地卡**（占通用槽、唯一资产、不占轴图标、不改槽位结构）；归属为**元素 §3 的场地卡 E-f3**，**替换原「灼热之地」**（全场 DoT，与荒野「尘暴」/「荆棘丛」重复）。因此每阵营仍是 **9 增益 / 7 消耗 / 4 场地**，总场地卡仍 20 张。
12. **属性类效果是否统一改成“准备阶段生效”**：「共鸣领域」的属性加成已定为开战前生效（换来零战斗内结算，以及“幻象出现时已带加成、不重复施加”）。但本表里还有战斗内触发的加属性卡（如元素「启迪」施法 → 全队 +智力），它们要么改写触发方式以适配新时机，要么保留即时生效并明确“战斗内属性可以随触发变化”（Dota 里属性变化会连带改生命上限、攻速、护甲，是最容易出问题的一类）。
