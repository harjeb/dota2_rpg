## 1. 全局规则

### 1.1 类型配比（沿用旧表结构）

每阵营 **20 张 = 增益 9 + 消耗 7 + 场地 4**，5 阵营共 100 张。

| 类型 | 行为 | 进化提升 |
| --- | --- | --- |
| **增益卡** | 持续被动，开战即生效，本场战斗 | 数值 |
| **消耗卡** | **战前设定触发条件，战斗中自动触发**；本场用掉即失效，战后回到卡库 | 数值 + 本场可用次数 |
| **场地卡** | 开战生成**覆盖全战场**的场地效果（无范围、不锚定装备者、不跟随移动）；**开战生成后永不失效**（装备者阵亡 / 复活 / 换人都不影响） | 数值 |

### 1.2 等级分档（沿用 `CARD_SYNERGY_AXES_V1.md` §1.1）

所有效果写成 **Lv1 / Lv2 / Lv3** 三档，按**装载等级**结算。累计同名 1 / 2 / 3 份 → 拥有 Lv1 / Lv2 / Lv3；准备阶段可挑 `1 ≤ 装载等级 ≤ 拥有等级 ≤ 3`。

- **曲线 6 / 10 / 15**：Lv1 是**弱化版**（故意打不出强度），Lv3 才是完整效果。
- **COST 仍按装载等级**：普通 1/5/10、强力 1/6/15、顶级 1/8/20。
- 数值全部是占位，只表达 `Lv1 < Lv2 < Lv3`。

### 1.3 作用对象

**所有效果作用于所有友方**（`FACTION_CARD_MODE_DESIGN.md` §1.1），装备者只提供槽位。**场地卡覆盖全战场**（§1.6），没有范围概念。其余卡里写「XXX 范围」的（一次性爆发伤害、范围减速/击退等），指触发瞬间以**装备者**为中心的圆形范围，只在那一次结算时生效。

### 1.4 轴与图标（9 个图标封顶）

①生命 ②护盾 ③魔法 ④充能层数 ⑥控制 ⑦节奏 ⑧死亡印记 ⑨重生 ⑩施法。

- ⑤召唤物轴**并入⑨重生**（召唤物的出口就是阵亡/献祭），共用 1 个图标。
- 每张卡在卡面只标**它所属的那一个轴**的图标；不属于任何轴的卡（纯功能卡）不带轴图标。
- **配比规则**：每轴 ≥5 张、≥3 阵营。校验见 §2。

### 1.5 消耗卡：按"物品 / 神符"的思路设计

消耗卡不再是"受伤反弹"这类被动小效果，而是**一次性、限时、全队共享的强力 buff**，手感对标物品与神符：

| 设计要点 | 规则 |
| --- | --- |
| 触发 | **卡自带默认触发条件**（多数是"开战第 5 秒"），玩家可用 §10 的条件系统改成自己的条件；**不做战斗内手动点击** |
| 时效 | 多数是**限时 buff**："X 秒内全队……"，到期即结束 |
| 次数 | 本场可用次数 = 装载等级（**Lv1 / Lv2 / Lv3 → 1 / 2 / 3 次**） |
| 计数域 | 本文的消耗卡默认**全队共享次数**（因为是全队受益）；这是 §9 待确认项 |
| 强度 | 因为是限时 + 次数受限，允许出现"**X 秒内基础攻击力 +80%**"这种平时不会给的倍率 |

本文用到的消耗卡范式（对照用户给的例子）：

| 范式 | 例子 | 出处 |
| --- | --- | --- |
| 限时基础攻击力 | 8 秒内全队基础攻击力 **+40% / +60% / +80%** | 文明「军团冲锋」 |
| 限时技能增强 | 10 秒内全队技能增强 **+20% / +30% / +45%** | 元素「奥术神符」 |
| 急速 | 8 秒内全队攻速 **+25 / +40 / +60**、移速 **+8% / +12% / +18%** | 文明「急速军令」 |
| 持续回血 | 12 秒内全队每秒恢复最大生命 **0.6% / 1.0% / 1.5%** | 神域「圣言祝福」 |
| 持续回蓝 | 12 秒内全队每秒回蓝 **+12 / +20 / +30** | 元素「秘法涌泉」 |
| 减 CD + 减蓝耗 | 12 秒内全队冷却 **−15% / −22% / −32%**、技能耗蓝 **−15% / −22% / −32%** | 元素「冷却循环」 |
| 限时吸血 | 12 秒内全队攻击吸血 **+15% / +22% / +32%** | 深渊「亡魂契约」 |

### 1.6 场地卡：覆盖全战场（已确认）

**场地卡覆盖整个战场，没有范围参数**：不锚定装备它的英雄、不跟随移动；战场内所有相关目标（按各卡效果，敌方或友方）无论距离多远都受影响。装备者阵亡则整场场地失效，复活不恢复。场地卡占**通用槽**，不是召唤物，不占单位数、不被驱散。

- 强度旋钮只有 **Lv1 / Lv2 / Lv3 数值**，不再用「范围大小」区分强弱（旧稿「范围 500 更强」的说法作废）。
- **不同场地卡可以叠加**（已确认）：各自独立结算、同时作用于全场，所以"叠加"就是**场地数量本身**，跟站位无关。场地数量天然是一个可读的量，**场地流轴 + 场地流核心卡**的思路草案见 `CARD_SYNERGY_AXES_CANDIDATES.md` §H。
- **永不失效**（已确认）：装备者阵亡、复活、换人都不影响已生成的场地，持续到本场战斗结束。因为不会被"击杀携带者"解除，场地层是最可靠的一层，强度刹车只剩 Lv 数值、通用槽机会成本与全局上限。
- 多个不同场地卡可共存；唯一资产下同名场地卡不可能出现两张。

本文覆盖用户点名的六种场地效果：

| 需求 | 卡 | 效果方向 |
| --- | --- | --- |
| 全场沙尘暴 | 荒野「尘暴」 | 敌人持续魔法伤害 + **命中率下降** |
| 巫医式回血 | 神域「巫毒回响」 | 友军每秒恢复最大生命的**较高**百分比（全场回血，数值最高的一档） |
| 全场减速 | 元素「静电力场」、深渊「恐惧领域」 | 敌人移速下降 |
| 减攻速 | 文明「硝烟地带」 | 敌人攻速下降 |
| 强力减治疗恢复 | 深渊「枯竭领域」、深渊「瘟疫爆发」 | 敌人受到的治疗 **−30% / −45% / −60%** |
| 奥术诅咒 | 元素「奥术诅咒」 | 敌人**每次施法**受到伤害，**且可叠层** |

## 9. 待确认项

1. **消耗卡的次数计数域**：本文按**全队共享**（Lv1 / Lv2 / Lv3 → 1 / 2 / 3 次）。旧框架默认"各自计数"（`FACTION_CARD_MODE_DESIGN.md` §1.1），两者必须选一个并写进卡面。
2. **消耗卡的触发条件由谁定**：本文给了**内置默认触发条件**（多数"开战第 5 秒"），玩家可用条件系统覆盖。这与 §14-7 的"抽到就能用 vs 玩家配置"是同一个问题。
3. **⑥控制轴 12 张是否拆轴**：若嫌 ⑥ 过大，把"减治疗"独立成候选池里的 D 伤口轴（顺带收容"伤口叠层"）。
4. **纯功能卡 28 张是否够格**：这些卡（限时 buff、直接伤害、治疗、场地数值）不带轴，是"不参与联动的工具卡"。若希望每张卡都带轴，需要再分配。
5. **场地卡的叠加上限**：治疗类场地（圣域 + 巫毒回响 + 荒野呼唤 + 补给线）可以同队共存，合计每秒回血过高时必须设全局限额（`FACTION_CARD_MODE_DESIGN.md` §9 是旧 demo，需重定）。
6. **倍率类限时 buff 的上限**：「军团冲锋」+80% 基础攻击力、「奥术神符」+45% 技能增强这类数字是**手感锚点**，不是平衡结论，需要在无尽模式实测波次里校。
7. **超上限加值的属性口径**（`FACTION_CARD_MODE_DESIGN.md` §6.2）：本表 100 张卡全部落地后，加值口径要重新选（不要百分比）。
8. **Lv1 完全不给轴机制的卡**：本表里「狂暴」「血誓」等在 Lv1 已给弱化机制；若要更保守，可改为 Lv1 只给纯数值、Lv2 起才给轴机制。

9. **消耗卡 / 增益卡里的一次性范围是否也改全战场**：本文还留着「XXX 范围敌人」的卡有「盾爆」、「霜缚」、「法力虹吸」、「元素坍缩」、「爆裂符文」、「齐射」、「神罚」、「恐惧之触」、「血债」、「遗恨」、「撕咬」。它们不是场地卡，范围只在触发瞬间结算一次；若希望所有卡统一按全队 / 全场口径，应逐张改为全战场敌人。

10. **场地流的强度刹车**：场地卡已经全场、永久、可叠加，且不会因装备者阵亡而消失，所以没有"击杀携带者解除场地"的天然反制。刹车只剩四条：Lv 数值、通用槽机会成本（每张场地卡都要挤掉一张增益/消耗卡）、`FACTION_CARD_MODE_DESIGN.md` §9 全局叠加上限、以及核心卡自身的"最多计 5 张"限额。是否把 20 张场地卡统一提到**顶级 COST 档**（1/8/20）待定。
11. **场地流核心卡放在哪一层**：作为独立的**核心卡 / 特殊卡**（不占轴图标，先做 1 张验证手感），还是纳入基础卡池（要占第 10 个轴图标，且必须满足"每轴 ≥5 张、≥3 阵营"）？四个候选思路见 `CARD_SYNERGY_AXES_CANDIDATES.md` §H。
