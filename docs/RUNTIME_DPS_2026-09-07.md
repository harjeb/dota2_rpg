# 准备区余额、点地施法与战斗 DPS（2026-09-07）

对应 Beads `dota2_rpg-ccz`，承接 `e2c4198`。此前版本的游戏内反馈仍未通过验收；本轮不能用离线检查替代实际游戏结果。

## 原因与改动

准备区每次 Think 已读取原生钱包，但缺少独立的余额广播条件。现在将钱包和最后一次发送的 `rpg_shop_state` 余额比较，购买/退款即使未改变装备快照，也在下一次准备区 Think（0.1 秒）推送余额；其他钱包读取不会吞掉更新。

点地技能的目标坐标曾被传入 `GetCastRange` 的实体参数，接口错误被捕获后返回零距离。现在只传单位实体或 nil，保留显式范围覆盖，并将点地施法的单位目标转成坐标。充能技能有剩余次数时不再被充能恢复计时单独拦截，仍检查完整可施法状态。

开战时收起两侧条件编辑框，仅在进入战斗的阶段边沿执行，保留恢复按钮。敌方编辑器改为服务器实际生成的单位名单，支持中立单位及可变数量。

右侧 DPS 按本场服务器 `entity_hurt` 事件中的正数 damage 汇总。双方单位按实际实体 ID 区分；中立波次使用逻辑敌方阵营。普攻、技能和物品分别统计，包含每个受击目标的分布。只统计登记的双方战场单位之间的伤害，已登记英雄拥有的召唤物可以归属到英雄；环境伤害、友伤及未登记受害者不计。每 0.5 秒推送，战斗结束冻结计时，下次开战清空。当前分母是整场经过的游戏时间，不是各单位的存活时间。
