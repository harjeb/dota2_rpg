# 通用条件实现与使用

本轮实现通用条件功能，包括矢量施法和普通引导技能的基础释放。英雄独有资源、连招、形态、落点优化和特定释放流程只登记，不提供专用执行逻辑。当前通用推荐方案的保守统计由 [覆盖审计](CONDITION_COVERAGE.md) 自动生成，不把原生技能效果或简单下令等同于掌握全部机制。

## 条件分层

| 层次 | 作用 | 例子 |
| --- | --- | --- |
| 使用条件，最多 4 项 | 决定当前是否考虑这条动作，全部满足才继续 | 自身血量 ≤ 40%；附近敌人 ≥ 2；战斗经过 10 秒；当前技能剩余次数 ≥ 1 |
| 目标筛选，最多 4 项 | 对同一个候选目标逐项判断，全部满足才保留 | 友军血量 ≤ 70%；近期受伤；不是自身；正在施法 |
| 目标排序，最多 2 项 | 在合格候选者之间依次比较 | 先选血量百分比最低，再选最近 |
| 普通动作选项 | 控制原生单位、地点、无目标和开关动作 | 原生单位/地点分支；开关开启或关闭；原生圆形范围至少覆盖几个目标 |

矢量技能使用相同的通用条件和筛选，默认选择原生射程内最近的合法目标，以其位置作为起点，沿施法者到目标的方向给出第二点；不增加专用条件或方向配置面板。第二点仅用于确定基本方向，不承诺技能的实际长度、落点收益或第二次命中。普通引导技能按通用条件启动，引导期间不会被后备普攻或其他规则抢断，交由技能原生逻辑结束。

使用条件包含生命、魔法、属性、战场人数、附近人数、已死亡人数、近期伤害、时间、动作次数/历史、技能充能、普通召唤物数量，以及通用状态存在、层数、剩余时间。目标筛选包含资源、距离、附近人数、英雄/普通单位/召唤物/幻象、归属、施法与控制状态、免疫、可驱散状态及通用 modifier/tag。高级状态字段由使用者明确配置，本版不内置任何英雄专属 modifier 配方。

同一条规则内部使用 AND。需要“低血量或刚受伤”时，分别建立两条规则。每位英雄最多 32 条；技能规则先于普通攻击检查，普通攻击作为后备动作。动作时间和次数记录成功下达的命令，不等同于技能命中、伤害或完成。

## 操作方法

1. 选择我方英雄，选择本条动作，再点击“条件设置”。
2. 普通技能可以选通用推荐方案，也可以直接填写使用条件、目标筛选和优先级。推荐方案只修改弹窗草稿。
3. 点击“应用”才提交；取消不改变已编辑规则。服务端拒绝时会显示原因，较旧请求的返回不会覆盖新结果。
4. 开关开启和关闭分别配置为两条规则，给开启、关闭阈值留出间隔，避免反复切换。

比如治疗友军，可以筛选“目标生命百分比 ≤ 70%”，按“最低生命百分比”排序；不必用“任意友军受伤”替代选中目标的状态。普通范围攻击可设附近敌人数作为使用条件，或启用原生圆形范围的命中数检查。命中数填 0 表示不使用此检查，不填写也不会强迫非范围技能通过范围门槛。

动作列表使用原生技能名称作为稳定标识，保留可配置的额外主动技能和多个大招。纯被动不作为施法动作。读取服务端规则、英雄重生、换位和切换头像不会自动提交默认规则覆盖原有设置。正常游戏中敌方规则仅供查看，工具模式可编辑实际敌方单位。

## 执行边界

执行前仍检查学习等级、原生可用状态、冷却、魔法、充能和控制状态；已有施法前摇和持续施法期间不会被其他规则抢断。单位目标使用原生目标约束，地点目标使用实际位置和原生距离。只在原生提供的圆形半径有效时做范围人数估计，不推断线形、锥形、轨迹或移动后的命中。

不实现残岩准备/消费、卡尔元素组合、特定引导子动作及提前释放、树木施法、专属朝向准备、矢量落点优化、远端陷阱/分身目的地、节奏/形态调度或召唤单位控制。这些记录在 [独特机制登记](UNIQUE_SKILL_MECHANISMS.md)。普通条件可以用于具有复杂效果的技能，但不因此宣称自动掌握该技能全部机制。
