# 无尽模式 UI103：100 张基础卡接入

本轮按用户确认补齐缺失设计参数和底层功能。100 张基础卡均有运行时定义并进入对应阵营的购买池；专属卡继续暂缓。继续复用正常模式的英雄、技能、装备、战术和关卡系统，卡背不变。

精确三档数值与统一规则以 [BASIC_CARDS_V1.md](BASIC_CARDS_V1.md) 为准。元素 E-c1/2/3/5/6/7 明确为单次触发；E-c4 使用共享 1/2/3 次。场地没有携带者施法归属，携带者阵亡不使场地结束。

风暴场与黎明之墙使用原生粒子资源，并在预载、到期和战斗停止时管理生命周期。兽穴和电环的位置从存活非卡牌战斗单位的包围盒向外扩 200 后采样。兽穴的大野池为人马征服者、萨特地狱使者、黑暗巨魔召唤法师、地狱熊怪粉碎者；远古池为黑龙、花岗岩傀儡、远古雷肤兽，池内等概率。共鸣增幅可延长兽穴单位寿命，但不提高数量上限；达到上限时跳过该次召唤，不补发。卡牌单位通过原生技能产生的后代召唤物及所属伤害 thinker 继承卡牌生命周期；到期和战斗停止时清理，清理死亡不触发阵亡收益，不影响普通英雄的无关召唤物。

## 原生兼容范围

护盾增幅按物理、魔法、全伤害三类在对应吸收回调中结算。默认登记无光之盾、烈火罩、防御矩阵、洞察烟斗、长盾/炎阳纹章的共享护盾 modifier，以及项目开场护盾。炎阳纹章的护甲 modifier 不生成额外容量。新增来源可通过 `Effects.RegisterBarrier(name, reader)` 登记。

额外容量仅在原护盾施加或检测到刷新时授予，绑定原 modifier 的寿命；轮询与增幅变化不会使其回满。默认读取原生技能的容量 special；未登记的原生护盾、额外天赋或特殊动态容量需要相应读取器。魔法护盾的蓝量转换、固定伤害格挡、闪避及法术抵挡不属于此有限容量护盾范围。

强幻象使用原生身份和属性声明，并通过正常施法指令执行；没有跳过施法条件直接调用 `OnSpellStart`。原生幻象技能/物品例外、原生护盾回调顺序、客户端粒子显示仍需实际 Dota 客户端验证。任意隐藏永久 modifier 的完全继承、失败重试时原生不透明状态恢复，继续由现有跟进任务覆盖。

## 验证与交付边界

本机没有 Dota/Workshop，以下均为源码、Lua 引擎接口模拟和 Panorama 事件联调验证，不能等同于实际游戏试玩：

- 100 张运行时定义、零排除项；剩余 10 张通过真实服务器报价、购买、装备与预算流程。
- 卡牌效果回归 **555 项断言通过**，覆盖重生形态继承、共享次数、过期增幅、护盾分类、连续灼烧、移动电环、墙体上限、后代召唤与原生伤害 thinker 清理。
- 野怪集成回归通过真实战术桥与技能指令适配器验证人马践踏，并验证召唤物不延长英雄全灭后的战斗。
- 粒子接口验证控制点、收缩、到期销毁和重复停止；无引擎渲染验证。
- 原生界面联调、无尽关卡/重试、100 卡目录生成校验、完整安装包模拟和正常玩法相关回归。

主包与独立无尽包的中英文可见标记均为 **103**。完整安装仍使用 `scripts/install-endless-ui.ps1 -DotaPath <Dota目录> -Compile`；模拟安装核对本地化文件哈希，实际编译与地图启动需在有 Workshop 工具的机器执行。启动地图为 `dota2_rpg_endless / dota2_rpg_demo`。
