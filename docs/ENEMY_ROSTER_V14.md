# v14：64 种敌方英雄与低重复关卡阵容

## 结果与范围

此前 30 关共使用 16 种敌方英雄，107 个英雄位置中，莉娜和冰女各出现 10 次。v14 将实际关卡英雄池扩充到 **64 种**：21 个英雄关卡、107 个英雄位置；43 种英雄出现两次，21 种只出现一次。所有英雄最迟在第 25 关完成首次出场。

同关无重名英雄，相邻两个英雄关卡之间也无重名（中间插入野怪关仍视为相邻英雄关）。同一英雄再次出现至少间隔 **10 关**。阵容固定，重载或重试不会重新抽取敌人。

保留每关敌人数、装备数量、等级、强化数值、Boss/精英标记、野怪阵容、奖励与时间配置。与提交 `25726a2` 的两份关卡数据逐字段比较，差异仅为英雄 `unit`、`ai` 和 `items` 内容；装备数量保持一致。新增英雄会改变战斗组合与实际难度，未声称已经完成实机平衡验收。

## 出装与技能

`scripts/author-enemy-roster.py` 按前排、输出、辅助三个独立池轮换，先用完该池英雄才再次使用。每关含三种定位，后期增加第二前排或辅助。`ai` 仅控制普攻优先级；技能目标仍由 v13 的原生技能行为与目标阵营生成，不把辅助英雄的第一个技能直接当作治疗。

`scripts/author-enemy-equipment.py` 覆盖全部 64 种英雄，每种六档出装，并支持特殊的双装备位置。原有 16 种英雄保留其完整出装，新英雄按定位开局，并明确指定核心、功能、防护和后期升级。例如：

- 圣堂刺客：黯灭、跳刀、黑皇杖，后期暴击。
- 幻影长矛手：散失、夜叉，后期幻影斧、龙心。
- 拉席克：血精石、慧夜对剑、黑皇杖、希瓦。
- 莱恩：跳刀、推推、永恒之盘、神杖。
- 食人魔魔法师：推推、以太、微光、羊刀；不占用装备位购买针对打钱的点金手。

已有预缓存会遍历 `levels.kv`，原生技能学习与敌方基础规则会按出生英雄处理，无需把敌人加入玩家招募池。64 个英雄 ID 均存在于仓库的原生技能快照。基础规则覆盖不等于逐个英雄复杂连招和原生特殊机制的实机验收。
