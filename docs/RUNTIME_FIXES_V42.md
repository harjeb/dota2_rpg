# UI42：完整可用物品掉落池与彻底新局

## 掉落范围

原关卡仅在九种重复装备之间掉落。现在每次成功掉落从本机 Dota 原生物品定义与当前中立轮换生成的池中抽取：**351 个源条目、349 个实际发放物品名**。

| 类别 | 条目 |
|---|---:|
| 普通装备、散件和消耗品 | 187 |
| 实际可用配方卷轴 | 79 |
| 当前中立装备 | 49 |
| 当前中立附魔 | 19 |
| 肉山奖励、免费眼等特殊物品 | 17 |

这里的“全物品”是完整可用原生物品池，不生成内部自动合成公式、已废弃定义、测试／活动专用实体或依赖特定英雄来源状态的物品。193 条排除记录及逐条原因保存在 `scripts/data/campaign_loot_catalog.json`：108 条非当前轮换中立定义、37 条零价内部合成公式、31 条原生 IsObsolete、8 条活动／测试定义、5 条英雄绑定机制、2 条旧信使、1 条拾取触发制作货币、1 条会在指挥官身上自动消耗的福佑配方。

魔晶、已消耗神杖的商店版本映射为可转交的肉山魔晶／福佑，避免在共享仓库小精灵上直接消耗。这两种实际发放名称各对应两张源条目票，其余一张。每次成功判定在 351 条目中等权抽取，可重复；不是按物价加权。

每关仍只有三次独立掉落判定，避免扩大物品池后一次生成数百件物品：普通／英雄关为 35%、30%、20%，Boss 为 60%、50%、25%，每次结算最多三件。平均分别 0.85 和 1.35 件，保持原总期望。胜利结算只处理一次。

仓库满时奖励保存在当前局待发放队列，腾出空间后继续发放。不朽盾复用已有实体保留与转交路径。原生创建／加入发生不明确失败时，条目隔离保留而不自动重复生成，以免重复消耗／发奖；这不等于保证所有失败最终交付。结算列表包含已获得但尚待入库的奖励。重开会废弃旧队列和旧发放回调。

新增 `scripts/author-campaign-loot.py` 可从安装的 VPK 重新生成目录和运行时 Lua 表。没有在启动时创建／同步预加载整个物品池，保留 UI41 首关加载优化。特殊中立附魔槽、肉山物品使用及原生配方合成仍需实机验收。
