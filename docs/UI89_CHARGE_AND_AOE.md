# UI89：蓄力配置与范围威胁应对

条件设置新增可选的“蓄力释放”。在已适配的启动技能上，可选择“指定蓄力时间”或“最大蓄力”；关闭时沿用原有行为。它是行动配置，不占用使用条件槽位，也不受“同时满足／按优先级”的组合方式影响。

指定时间支持 0～120 秒及小数，默认 1 秒；实际等待不超过技能原生最大蓄力时间。0 表示原生释放允许后尽快释放，不代表下令当刻就能释放。最大蓄力按技能原生有效蓄力上限处理。应用后再次打开、服务端同步及快照恢复均保留选择；改为最大蓄力会清除指定时间，关闭、清空设置或更换动作会移除蓄力配置。

已审核的启动技能：

| 技能 | 原生标识 |
| --- | --- |
| 风行者：强力击 | `windrunner_powershot` |
| 光之守卫：冲击波 | `keeper_of_the_light_illuminate` |
| 齐天大圣：乾坤之跃 | `monkey_king_primal_spring` |
| 百戏大王：驯兽术 | `ringmaster_tame_the_beasts` |
| 獸：突 | `primal_beast_onslaught` |
| 森海飞霞：狙杀 | `hoodwink_sharpshooter` |
| 炼金术士：不稳定化合物 | `alchemist_unstable_concoction` |
| 神谕者：气运之末 | `oracle_fortunes_end` |

不稳定化合物使用有效酝酿上限；投掷仍按原规则筛选合法、射程内的敌人，配置为只选自身就无法投掷。投掷指令提交后等待原生确认，仍在酝酿且释放被打断或未确认时允许有限重试，最多提交三次。突使用起步蓄力时间。控制、打断、技能替换和原生释放是否可用仍会影响执行，不能保证命中。普通持续施法技能及对应结束按钮不会显示此配置；已支持的独立结束动作规则仍使用原有流程。光之守卫灵魂形态下由独立灵体蓄力、英雄自身不引导的情形尚未适配；不会套用英雄的计时强行释放。

服务端字段为可选的 `action.charge_mode = 'time' | 'max'`。`time` 必须携带有限数值 `action.charge_time`（0～120 秒）；`max` 清除多余时间。不配置模式的旧规则保持字段缺省。非法模式、无模式的时间、非蓄力动作以及不一致的动作名称会被拒绝；无效保存不会替换已保存规则。前端输入会规范到允许范围。

U45 范围威胁应对覆盖已释放、可见且已适配的范围技能，包括延迟爆炸、持续区域和行走路径避让。具体审核范围以 [AOE_THREAT_COVERAGE.md](AOE_THREAT_COVERAGE.md) 为准；未列出的技能不应视为已支持。仍可选择走出范围或使用本行技能／装备防御、位移。含此条件的行始终要求真实范围威胁和反应时间均成立；其他优先级条件不能绕过这个要求。反应区间默认 80～500 毫秒，可配置 0～2000 毫秒，不根据施法前摇提前应对。

炸弹人另外接入真实炸弹观察：感应地雷、死亡炸药桶，以及存在对应原生单位时的旧版遥控炸弹／静滞陷阱／圈套。粘性炸弹检查投掷、追踪、倒计时的原生状态和附着单位；隐藏炸弹不会透视，已知位置仅短时保留。反应式电击跟随实际被施加的友军，爆破起飞按释放后的原生飞行时间估算落点。感应地雷的离开期限包含发现延迟余量，但无法读取其私有触发计时，不能保证每次成功躲开。

当前为 84 项技能／物品配置加炸弹实体观察，仍有电炎绝手大招逐发落点、部分多段范围和升级变化等未覆盖项；“所有持续／延迟 AOE”尚未全部完成。完整缺口见覆盖文档，不把未观测到威胁当作安全证明。

离线验证覆盖蓄力菜单、时间输入、关闭与清空、切换动作、快照回读、扁平事件与服务端保存，以及数值和能力范围校验。`tests/charge-configuration-ui.test.js` 和 `tests/charge-configuration.test.lua` 为新增回归。中英文本均显示 UI89。离线模拟不等于原生游戏验收；安装后须核对中英 locale 与源码一致，再实测各技能的真实蓄力计时、原生释放、控制中断和换关清理。本轮 `LUA_BIN=luajit python scripts/test-all.py` 为 143/143 通过，报告位于 `tests/results/reliability-regression.json`。安装命令 `scripts/install-addon.ps1 -Compile` 因默认 Dota 目录不存在而失败，未进行 Workshop 编译或实机验证。
