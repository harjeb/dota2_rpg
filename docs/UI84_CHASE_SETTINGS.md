# UI84：可配置追击超时

行动设置选择「自动接近目标」后显示「追击超时（秒，0.1～5）」输入框。每条规则独立配置，支持小数，默认 3 秒；空值或非有限数字回落到 3 秒，越界值限制到 0.1～5 秒。切换为等待进入射程时隐藏输入框并保留数值，再次启用自动接近时继续使用。

技能、物品、普攻及兜底普攻的默认追击超时统一为 3 秒，默认最大追击位移从 1200 改为 2000。距离仍按当前位置与本次追击起点的直线距离计算，不是累计路径长度。已有规则显式指定的合法超时及距离仍予以保留。

超时字段贯通设置草稿、客户端发送、服务端规则、快照及旧格式恢复，避免重新打开或恢复规则后丢失。服务端原有 0.1～5 秒校验范围不变。

追击到期或超过距离后仍按既有引擎流程重新评估规则，满足条件的同一规则可能立即再次开始追击。本次未改变规则重试和优先级语义。

验证：使用 `LUA_BIN=luajit` 运行 `python scripts/test-all.py`，131/131 组离线检查通过；包含默认/自定义超时、2000 位移边界、设置保存回显、服务端快照恢复及非法输入归一化。`git diff --check` 通过。中英文版本标记均为 84。未安装或执行 Dota/Workshop 游戏内验收。
