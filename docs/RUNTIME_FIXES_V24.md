# v24：持续移动、站位策略、目标阵营与合并结算

日期：2026-09-09。运行标记 `rpg-runtime-v24-20260909`，界面版本 24。

## 持续移动

行动列表新增“持续移动”。在条件设置中可以选择跟随、穿越、绕行、多目标轮换，设置自身原生 Buff、触发技能、距离、方向、时限、目标失效后是否重选、循环及是否允许更高优先级规则打断。

缩地预设使用 `modifier_weaver_shukuchi` / `weaver_shukuchi` 和多目标轮换；践踏预设使用 `modifier_primal_beast_trample` / `primal_beast_trample` 和绕行。两者开启循环，移动半径 150，安全时限 15 秒；Buff 消失会提前结束。一般空白移动参数默认 5 秒、距离 150。原生技能仍由独立施法规则释放，移动动作本身不代替施法。通常把移动规则放在对应施法规则之前：尚未触发时跳过，新的原生施法事件与 Buff 满足后开始。

现有 U/F/P 条件与 F39 指定敌人继续生效。多目标轮换按现有筛选和优先级逐个选择未访问目标，循环完成后才重置访问记录。当前移动段锁定目标，目标死亡/不合法时默认结束；明确允许重选才换人，F39 不会被绕过。绕行考虑双方碰撞体积，自动方向遇阻可换向。原生导航仍决定实际路径，无法移动会结束。

持续期间暂停该英雄的普通攻击、其他技能和物品规则及兜底攻击。关闭原生空闲索敌并把索敌距离设为零，结束后在战斗中恢复原值；准备阶段保持不索敌。小小自动抓树也遵守独占状态。控制、引导、施法前摇及原生强制位移不会被移动指令打断；Buff 消失、死亡、超时、目标失效和持久寻路失败均有退出路径。可选的高优先级打断不会用清理 STOP 取消刚开始的新施法。

新施法通过原生 `OnAbilityExecuted` 观察，历史指令不能冒充新施法。同次 Buff/施法不会因超时重复启动。隐藏事件观察 modifier 不可驱散，在同一实体复活时仍可工作；关卡重置显式移除。桥接层在辅助施法期间暂时不评估单位时，继续保留观察器，避免漏记施法完成。

## 攻击与技能站位

条件设置中新增默认、固定距离、攻击射程、施法射程等策略；施法射程仅用于技能。攻击射程实时读取，目标距离位于射程内侧，容差上界不会超出真实攻击射程。

普攻风筝必须先收到原生 `OnAttack` 出手事件，`OnAttackStart` 只清除旧出手窗口。不会把攻击指令、前摇时间或伤害命中当成出手证明。窗口按当前攻击间隔计算，下一次攻击前提前关闭；攻速过高时可能没有移动窗口。原生引导和施法前摇不受打断。站位仍受该规则的使用条件和目标限制约束。

## 自己与友方目标

原有“目标范围”位于详细条件下方，容易与英雄/小兵的类型筛选混淆。本次将它移到条件设置最上方，明确标注“目标阵营：自己 / 友方 / 敌方”，并补充友方跳跃、治疗和 Buff 的使用提示。需要仅选友方英雄时，选择友方阵营并添加英雄筛选；技能自身的原生类型限制仍然有效。

针对玛西单独验证了 `marci_companion_run`、`marci_bodyguard` 和兼容原生身份 `marci_guardian`：默认读取原生友方目标，二技能保留先设置向量终点、再对友方单位施法的原生命令对；Buff 技能对合法友方发出普通单位施法命令。错误敌方或不允许的自身目标仍被原生过滤拒绝。没有擅自重写玩家已保存的目标，已有错误规则需改选友方并应用。

## 胜利与掉落合并

掉落区成为 `BattleResult` 结算卡片的子面板。胜利标题、金币/经验奖励与掉落图标按垂直布局集中显示，去掉掉落区的独立浮层位置、背景边框，也去掉奖励文字中的重复掉落名称。收到结算消息即可显示父卡片，避免等待另一条战斗状态消息。无物品时不显示空掉落区；生命奖励仍复用该区域。掉落确认、3 秒收起和旧定时器隔离逻辑保留。
