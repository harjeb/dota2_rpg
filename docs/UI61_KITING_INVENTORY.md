# 界面版本 61：受阻风筝与两行装备列表

最大攻击距离站位继续使用英雄当前原生攻击范围和安全容差。后退目标被墙、树或其他不可通行区域阻挡时，尝试目标两侧的切向短步、较短的角落落点和角度候选。候选保持在攻击范围内，后退路径不主动切近敌人。选定的可用落点和方向会保留，避免每帧左右切换。

除了原生 `CanFindPath`，还对线段做有上限的通行格采样。若原生导航返回成功但英雄连续 0.45 秒没有达到进展阈值，会尝试换边；位移、目标移动或两秒后重新考虑原后退方向。原生单位碰撞和动态地形最终仍由 Dota 寻路处理，不能保证任何包围位置都有出口。所有候选都不可用时回到普通攻击判断。普攻站位仍须同一目标的真实攻击出手事件，且在下一次攻击前结束可移动窗口；不以攻击命令或前摇代替出手事件。

已装备和仓库列表各固定为 142 像素，即两行 70 像素装备卡片加边框。每行仍是两个装备格，额外装备在各自列表内滚动。右侧使用 6 像素深色滚动轨道和 4 像素金色滑块，并预留右边距；较矮屏幕仍可滚动整个装备内容，卷轴与魔晶商店排在两个列表之后。

中英文本地化的 `dota2_rpg_build_tag` 同步递增至 61。项目 `AGENTS.md` 记录后续界面改动须同步递增可见版本号，历史部署报告保留其原版本。

验证：97/97 组离线回归通过，新增站位测试覆盖后退、两侧选择、窄角、线段障碍、卡住换边、有效方向保持、恢复后重新探路、攻击窗口和无路时退出。Dota 原生 HUD CSS 编译通过；站位 Lua、HUD CSS 和两份本地化共四个源文件与本机安装副本逐字节一致。离线测试使用原生 API 模拟，并未操作或运行 Dota 对局；真实墙边移动、滑块外观与当前屏幕尺寸仍需在新一局验证。工坊大厅需要上传更新到原条目后启动新大厅。
