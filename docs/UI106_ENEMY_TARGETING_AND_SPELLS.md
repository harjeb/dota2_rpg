# UI106 — 敌方索敌与技能使用条件

## 索敌问题与调整

生成的敌方技能原来继承 `nearest`；部分关卡普攻用 `lowest_hp_pct`。前者始终打最靠近的前排，后者容易把“百分比低但仍有大量有效生命”的肉盾当成优先目标。

新增仅用于敌方真实英雄的软优先级 `enemy_combat_value`，按当前生命、对应伤害类型的护甲／魔抗，以及距离和超出攻击／施法距离的移动成本排序。纯粹伤害和无伤害类型不按抗性折算。这是选敌的近似评分，不是伤害预言；不会模拟反伤、伤害减免被动或完整的技能连招伤害。

- 射程内更容易击杀的后排可以胜过前排；可收掉的残血肉盾仍然值得优先处理。
- 近战追远处后排有较大成本，避免绕过整条前排追人。原有 `range_only`／`allow_approach`、原生目标合法性与施法检查保持生效。
- 指定控制（莱恩变羊／穿刺、暗影萨满变羊／枷锁、冰女冰封禁制、祸乱之源噩梦／魔爪，以及羊刀、深渊之刃、紫苑／血棘、吹风类敌方施放）优先打断正在持续施法的合法目标。
- 进攻物品使用同样评分。长戟自救推人仍选择最近威胁；治疗友军、蛋／墓碑的专门攻击目标不套用该评分。
- 幻象和普通召唤物有软性惩罚，并非禁止攻击。玩家规则和中立单位默认索敌不变。

## 技能条件

对照本机原生 VPK 的英雄定义核对了技能名称、队伍和行为类型。本轮增加6个具名策略：

| 技能 | 新的敌方默认策略 |
| --- | --- |
| 戴泽：薄葬 | 友军血量不高于35%；优先生命百分比最低者；不重复套已有薄葬的目标 |
| 神谕者：虚妄之诺 | 友军血量不高于40%；优先生命百分比最低者；不重复套已有虚妄之诺的目标 |
| 全能骑士：洗礼 | 友军血量不高于85%；优先缺失生命最多者 |
| 戴泽：暗影波 | 友军血量不高于85%；优先缺失生命最多者 |
| 亚巴顿：回光返照 | 主动施放增加自身血量不高于40%的门槛；原生自动触发不变 |
| 戴泽：结束虚无投射 | 禁止生成的AI规则自动按结束键，避免投射刚开始就自行结束 |

洗礼、暗影波采用治疗优先的保守默认策略，满血友军作为纯伤害跳板的进攻施放不在本轮策略内。原有目标过滤和技能使用条件追加保留；冷却、魔耗和原生施放检查仍由执行器完成。玩家手动规则与默认规则未套用这些限制。

巫医巫毒回复的原生 `does_heal_all_allies`、`does_damage` 会随命石改变；本轮未将通用治疗门槛套到这一切换技能上。
