## 用户确认的简化方案

| 类型 | 当前处理 |
| --- | --- |
| 固定陷阱、装置 | 使用现有普通点地动作、使用条件、目标筛选和优先级；保留原生地点合法性检查，不增加装置状态管理条件。 |

| 其他依赖树木的技能 | 继续普通条件与原生目标限制；不专门寻找树林或优化附加收益。原生目标不合法时跳过，作为用户接受的无效技能情形。 |

| 残焰与游魂 | 新增目的地选项，放置/移动与激活/返回各保留原生独立技能身份。 |
| 可控制召唤物 | 有普通攻击能力的召唤物攻击最近合法敌人；治疗守卫跟随附近存活友方英雄。固定装置及不可控制的原生效果单位保留原生行为。 |

小小自动抓树使用两秒临时树，通过 `GetTreeIdForEntityIndex` 转换树木 ID 后，经内部订单门发送 `DOTA_UNIT_ORDER_CAST_TARGET_TREE`。保留原生魔法消耗、冷却、持树 modifier 与攻击次数；没有直接添加模拟持树 modifier。短暂保留施法窗口，普通战术不会在同一时刻覆盖抓树命令；失败订单不占用该窗口。成功下令进入 U21/U22/U23 使用的动作历史，历史表示“下令”而非保证施法完成。

U33–U38 检查实际最近抓取候选的敌我、英雄/小怪身份及血量百分比；不先筛掉近处友军再假定原生技能会抓远处敌人。没有候选、距离并列、最近单位为肉山/远古单位或原生查询失败时保守拒绝；最终抓取和落点仍受原生技能约束。完整菜单现在有 **31 个使用条件、34 个目标筛选、13 个目标优先级，共 78 项**，见 `CONDITION_LIST_ZH.md`。

## 目的地与召唤物

残焰放置、残焰激活、先祖之魂、移动游魂的设置提供“按目标筛选与优先级选择位置”和“自身位置”。残焰激活另外提供：离自身最近、离自身最远、最靠近敌人、距最近敌人最远的己方残焰。

残焰选择只使用仍有效、存活、同阵营且属于当前施法者的原生残焰。使用选定残焰的位置发原生点地指令，途中经过其他残焰及最后移动效果由原生技能处理。普通目标筛选和显式范围命中门槛继续生效，没有自定义传送。移动游魂的零原生施法距离按其位置指令处理，避免被当作必须在脚下操作。目的地、施法方式、范围门槛经过服务端保存/快照/重建；切换动作时重置不适用的旧目的地。

召唤物按实际所有者追溯到当前上场单位；替补、无主单位、普通阵容英雄、残焰和游魂不被当作普通召唤物接管。对出生后才分配所有者的单位定期补查。内部订单通过同一订单门；受管理召唤物、天穹分身和特殊对象遵守战斗中的玩家订单限制。结算时清理普通召唤物和特殊对象；原生真实英雄克隆先停止行动，交由其本体的原生生命周期处理，避免主动删除克隆影响本体。天穹分身仍使用 v18 的原生攻击/寿命策略。

原生不可控制的士兵、附着效果和投射物不接管，避免关闭其原生攻击行为；可移动治疗召唤物当前明确识别治疗守卫，固定治疗/增益装置不能被强制移动。
