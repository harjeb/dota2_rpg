# UI28：右上角技能条件帮助

右上角新增常驻 `?` 按钮，点击打开独立帮助页面。左侧分类目录可搜索教程类型、示例技能或示例英雄；右侧显示技能图标、目标与排序、使用条件、目标筛选、操作步骤和适用限制。目录与正文分别滚动，切换正文回到顶部；支持关闭按钮、Esc 和点击遮罩关闭，重新打开保留所选章节。

先选择英雄和技能/装备，再打开条件设置，参考帮助填写并应用。帮助浏览不会提交规则。阅读时战斗继续计时，建议备战期间阅读。

## 类型统计

采用仓库已有 [G00–G21 技能机制分类](UNIQUE_SKILL_MECHANISMS.md)，排除 G14 纯被动后，以 21 类主动设置主题核对基础教学覆盖。本次 **17/21 类，80.95%**，整理成 **26 个浏览章节**；未计入 G18 再次释放/子技能、G19 自动法球与攻击时机、G20 专属矢量/双点/双目标、G21 英雄特有机制。类型覆盖表示该主题有可参考的基础设置步骤，不表示该类型的每个技能、全部专属机制或所有升级均已经适配。逐技能已审查预设范围保持独立统计，详见 [教程覆盖审计](CONDITION_HELP_COVERAGE.md)。

## 使用例子

连招章节提供跳刀接刃甲接斧王吼的三条规则：跳刀选择最近敌人；刃甲选择自身，添加“前置动作成功后”，指定同英雄的跳刀及 2 秒窗口；吼选择自身，用同样条件指定刃甲。各规则的其他条件仍需满足。前置成功施放不代表已经命中，也不会自动传递目标。

友方增益说明“优先队友”和“允许自身”，治疗和保护区分自身条件与目标筛选。充能、持续移动、标记、全图技能及特殊技能限制各自说明适用范围。
