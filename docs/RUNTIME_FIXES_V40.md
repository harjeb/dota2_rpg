## 敌方大招

敌方生成规则按原生 `GetAbilityType()` 稳定排序，大招先于小技能；救命／开战物品规则仍按现有顺序执行。术士先尝试地狱火，再进入三技能引导。大招未学、冷却中、缺魔法或没有合法目标时正常执行后续动作，不主动打断已开始的原生引导。骷髅王主动重生继续排除；玩家自行配置的规则不改顺序。

## 魔晶归属

原生购买会先在 assigned hero 小精灵上消耗魔晶，普通物品的事后转交流程来不及处理。UI40 只对魔晶拦截订单，验证当前所选的己方上阵／待命英雄，在原生升级确认后扣除 **1400**，并阻止原购买继续执行。重复、无有效目标、金币不足、其他购买未完成、授予失败均不扣款。每名英雄各购买一次，一秒补货，付费状态随阵容重建恢复。

当前原生 `server.dll` 注册的是 `modifier_item_aghanims_shard`，没有旧代码使用的 `_consumed` 名称；购买、品质和敌方授予入口已统一正确名称。存在 `HasShard()` 时以真实原生标记确认，不能只靠新增 modifier 判定付款成功。失败会移除本次未生效的新 modifier。已在旧局被小精灵消耗的历史购买不做推测退款。

## 白牛与远古

白牛 Boss 保持 20,000 最大生命、攻击伤害 +75%、额外护甲 +15，装备两枚未消耗银月。当前原生每枚装备提供 140 攻速，消耗仅提供 60，因此不自动消耗。

魔抗配置改为**常态最终目标 80%**：装备完成后读取原生魔抗，反算需要的乘算加成；重复应用先扣除旧加成，不叠加。原生基线高于 80% 时不削弱。后续 BKB 等临时效果仍可继续提高魔抗；校准应发生在准备阶段，没有临时增益时。骷髅王既有 32,000 最大生命与其他 Boss 加成保留。

生命／攻击倍率继续乘在关卡成长之后，护甲加在缩放后的原生基础护甲上。全部仍为原生 `IsAncient=1` 的远古；数量、种类、攻击倍率和其他配置保留。KV 与维护 JSON 独立更新，Excel／CSV 同步包含最终魔抗目标和双银月。

## 再来一次

生命耗尽后显示“再来一次：重试当前关”；最终通关显示“再来一次：从第一关再战”。保留英雄养成、装备、规则和金币，恢复 5 条生命，重建敌我阵容、屏障和商店，返回准备界面。普通中途胜败仍在三秒后自动推进／重试；技能测试维持自身重置流程。

服务器校验玩家身份、阶段和结算编号，防止重复点击、旧结算请求及旧延迟回调影响重开。终局状态在首次广播前设置，按钮立即可用。没有调用会正式结束 Dota 对局的 `SetGameWinner`。
