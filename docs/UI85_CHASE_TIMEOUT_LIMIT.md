# UI85：追击超时上限 120 秒

按用户要求，将追击超时范围由 UI84 的 0.1～5 秒调整为 0.1～120 秒。默认仍为 3 秒，默认最大追击位移仍为 2000。

同步修改设置输入、客户端序列化和服务端规则校验，以及中英文输入标签与版本标记。支持小数；超过 120 的有限数值限制到 120；空值或非有限数值在客户端仍回落到 3 秒。

使用 `LUA_BIN=luajit` 运行 `python scripts/test-all.py`，131/131 组离线检查通过。覆盖 120 秒保存回显、快照恢复、121 秒服务端限幅到 120，以及引擎追击到期边界。未执行 Dota/Workshop 游戏内验证。
