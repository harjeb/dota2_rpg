# v23：F39 指定敌方目标

准备阶段打开条件设置，在目标过滤中选择 **F39 指定敌方目标**，点击当前敌方头像选择具体单位。同名单位按阵容位置区分；英雄、野怪和 Boss 均可选，列表来自当前敌方 roster，而非全部英雄目录。清除该过滤条件后恢复普通目标筛选。

目标死亡、离场、阵营改变或其他条件不满足时，整条规则不执行，继续检查后续规则，不能忽略指定目标条件后自动换人。范围技能仍遵守原生范围效果，指定目标不代表范围内其他敌人免受伤害。距离、原生施法资格及其他过滤条件仍有效。

协议为 `specified_enemy` + `target_actor`，如 `ch05:enemy:npc_dota_hero_axe:0`。身份由当前关卡、单位名和出生时固定的同名序号组成，不使用可复用实体索引。保存/快照/重开保持身份；同关重试仍对应原阵容位置，下一关失效且不自动替换，编辑器显示“失效目标”。提交时要求合法当前敌方目标及enemy目标阵营；未选择目标或提交无效目标会由服务端拒绝。玩家已有的旧关卡规则仍保留并在执行时失败关闭。

界面仅对当前己方规则提供当前敌方头像；开发模式敌方规则没有有效对立目标元数据时不伪造选择。英雄头像使用 DOTAHeroImage，野怪使用原生 units 图片路径。实际图片显示仍需引擎验收。
