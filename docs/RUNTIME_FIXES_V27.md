# UI27：友方技能的两种目标预设

31 个已有友方单位技能的预设新增“优先队友”和“允许自身”按钮，包括普通增益、玛西/猛犸 Buff、治疗、保护、回蓝与解控。它们保留各技能原有的血量、受控、附近敌人等条件；玛西和猛犸继续采用 UI26 已移除附近敌人门槛的配置。

- **优先队友**：第一排序使用新增 P14 `prefer_teammate`，第二排序保留原来的最近距离或最低血量等策略。合法队友优先；没有通过原生目标、射程和规则筛选的队友时，才考虑合法自身。
- **允许自身**：自身与队友一起参与原有排序。允许自身不意味着强制对自身施法，也不会绕过技能原生的禁止自身限制。

范围是已有 31 个受支持的友方单位技能：13 个保护、7 个治疗、6 个普通增益、2 个解控、1 个回蓝、2 个玛西/猛犸 Buff。原生隐藏/被动或已标记不支持的技能不生成新预设；群体和仅自身技能的现有预设保持原样。有原生充能元数据的技能同时提供标记“需有充能”的对应变体。

## 使用

重新载入自定义游戏，确认“界面版本 27”。打开技能条件设置，点击“优先队友”或“允许自身”，检查预览后点击“应用”。预设替换该规则的条件和目标。自定义规则不会自动改动；生成默认规则仍保留 UI26 对玛西和猛犸的排除自身策略。

本次不自动判断 Buff 是否已覆盖全队，不实现防重复刷新。

生成器提供成对预设，前端按钮使用明确名称。后端 rule service 接受新优先级，selector 在合法候选间进行排序；Bridge、NetTable 与扁平参数支持保存回读。对应 overlay 同步新优先级。

完整 `python dota2_rpg_issue_fixes/tests/run_checks.py`、`tests/verify-addon.ps1` 和 `git diff --check` 通过。测试覆盖 505 个完整预设变体，条件后端 232 项检查；新增队友优先、独处、队友超范围、硬过滤、自身原生不合法、两个预设切换后的字段清理与保存回读。

原生 API 使用模拟；没有 Dota 实战验证。实战跟踪 `dota2_rpg-5c7`，本次实现 `dota2_rpg-zk9`。检查发现的既有 overlay U39 参数校验差异单独跟踪 `dota2_rpg-bf6`。
